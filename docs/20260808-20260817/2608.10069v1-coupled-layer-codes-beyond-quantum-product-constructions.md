## 摘要
乘积码是一类重要的量子纠错码，由多个输入码构造而成，可以产生渐近好的量子低密度奇偶校验码。在先前的工作中，我们展示了如何通过使用第二个码的校验来耦合第一个码的层，从而物理实现两个码之间的乘积。在这项工作中，我们通过引入耦合层码，进一步将乘积码构造与物质相的耦合层构造统一起来。基本策略是凝聚由泡利算符在第一个码的多个解耦层中产生的一般激发。凝聚由激发代数（编码激发）以及保持代数的映射来指定。这种层间耦合推广了物理学中的规范化的概念以及同调代数中的映射锥，并可用于产生非CSS码。作为示例，我们展示了耦合层码如何重现X-cube和Chamon模型。我们进一步通过允许在自由置换的群作用之外附加酉变换来推广平衡乘积码，并描述其对应的耦合层构造。特别是，我们展示了如何通过ZX对偶平衡来重现非CSS码，例如三维中的费米子环面码和三费米子Walker-Wang模型。

## Abstract
Product codes are an important class of quantum error-correcting codes constructed from multiple input codes, which can give rise to asymptotically good quantum low-density parity check codes. In previous work, we showed how the product between two codes can be physically implemented by coupling layers of the first code using checks of the second code. In this work, we further unify product code constructions with coupled-layer constructions of phases of matter by introducing coupled-layer codes. The essential strategy is to condense general excitations created by Pauli operators among multiple decoupled layers of the first code. The condensation is specified by an excitation algebra, which encodes the excitations, along with an algebra-preserving map. This coupling between layers generalizes the notion of gauging in physics as well as the mapping cone in homological algebra, and can be used to produce non-CSS codes. As examples, we show how coupled-layer codes reproduce the X-cube and Chamon models. We further generalize the balanced product code by allowing a unitary transformation in addition to a group action by free permutation and describe its corresponding coupled-layer construction. In particular, we show how balancing by a ZX-duality can reproduce non-CSS codes such as the fermionic toric code and the 3-fermion Walker-Wang model in 3D.

### 核心思想

- **耦合层码**：将第一个码（code 1）的多个解耦副本按第二个码（code 2）的稳定子/校验模式进行层间耦合，通过**凝聚一般激发**（不仅仅是单泡利X/Z激发）来实现新的稳定子码。
- **两个关键输入对象**：
  1. **激发代数（excitation algebra）**：由基础稳定子和特定泡利激发共同生成的代数（如X型激发代数 \(A_x\)、Z型激发代数 \(A_z\)，或更一般的X/Y/Z型激发代数）。
  2. **保持代数的映射（algebra-preserving map）**：将激发代数映射到辅助量子比特上的泡利算子，同时保持换位关系。该映射等价于同调代数中的**映射锥（mapping cone)**，并与物理中的**部分规范化（partial gauging）**、格点手术（lattice surgery）有紧密关系。

### 具体技术路线

- **CSS耦合层码（CSS Coupled-Layer Codes）**：
  - 利用链复形语言，将耦合构造表达为**映射锥的复合**（见图7），两个映射锥分别对应X型和Z型部分规范化。
  - 算法流程大致为：
    1. 对第一个CSS码的每个量子比特（按第二个码的索引）复制一层；
    2. 对第二个码的X型（或Z型）稳定子对应的每个稳定子代表，引入辅助量子比特；
    3. 执行**码切换（code switching）**：添加凝聚项 \( \alpha(e_x,a_2) \) 和 \( \beta(e_z,b_2) \)，它们分别凝聚X型和Z型激发；
    4. 保留与码切换对易的初始稳定子，得到新稳定子群，这些项对应最终码的X/Z稳定子。
- **非CSS推广（Coupled-Layer Codes）**：
  - 放弃链复形描述，直接以激发代数和代数保持映射为基本对象，允许输入码和输出码均为一般Pauli稳定子码（非CSS）。
  - 第二个码的稳定子仅限定为纯X、Y或Z型（纯泡利型），以保证凝聚项可对易。
- **广义商与e´m平衡积（Generalized Quotient and e´m Balanced Product）**：
  - 将群的对称作用从“自由置换”推广为“自由置换+逐位酉变换（transversal on-site Clifford unitary）”。
  - 特别关注**Hadamard（H）**作为酉变换的情况，称为**e´m对称（ZX-duality）**，并定义**e´m商**和**e´m平衡积**。
  - 耦合层构造通过选择第二个码的稳定子代表，对每一层施加 \(U_g\)（由群元素决定为恒等或Hadamard）后做凝聚，从而产生非CSS码。
- **平衡耦合层码（Balanced Coupled-Layer Codes）**：
  - 统一以上所有元素：一般激发凝聚 + 群作用（置换+酉变换）。形式上定义了凝聚项 \(A(e,\tilde{f})\) 和剩余稳定子 \(B(h_t,\tilde{q}_2)\)，并证明它们彼此对易（附录C给出详细证明）。

- **凝聚一般激发**（而非仅单泡利激发）可以产生比传统乘积码更广泛的稳定子码，包括X-cube、Chamon等分形码。

- **平衡耦合层码**是更一般的综合框架，涵盖标准平衡积码、e´m平衡积码以及一般激发凝聚。
- 该框架为未来构造新型量子LDPC码（尤其非CSS类）提供了理论工具，也为理解拓扑/分形相的可实现性提供了组织原则。

## 7. 优点

- **理论统一性强**：把看似不同的构造（张量积码、平衡积码、映射锥、部分规范化、格点手术、物质相凝聚）统一到少数几个概念（激发代数、代数保持映射、e´m对称）之下。
- **推广范围广**：同时支持非CSS输入/输出码、一般激发凝聚、以及带酉变换的群作用，明显超越以往乘积码框架。
- **与已知模型完美衔接**：能准确重现X-cube、Chamon、费米子环面码、Walker-Wang等众多著名模型，证明框架的扎实性。
- **数学严谨**：提供了逻辑算子计数、对易性证明、与辛对偶的等价关系等详细附录，理论可信度高。
- **潜在实用性**：提出将乘积码技术扩展到非CSS码的路线，可能有利于未来设计具有更好参数的qLDPC码。

## 8. 不足与局限

- **缺乏数值与参数化评估**：论文未系统评估所构造码的码率、码距、编码率噪声阈值等纠错性能；作者也承认某些构造（如4D量子码示例）会给出常数距离，说明**并非所有耦合层码都能产生优良参数**。
- **统一框架的具体例子有限**：尽管提出了“平衡耦合层码”这一最一般形式，但作者说明尚未找到超越之前构造的低维具体实例。
- **对一般化条件的假设**：在定义一般激发时，假设激发支持互不相交且被群自由置换；对任意激发并不普适。群作用仅限单比特Clifford，未扩展到簇内作用。
- **计算复杂度/实用性讨论不足**：未讨论这种构造在工程实现上的可行性、解码复杂度等。
- **无实验对比**：没有与传统最优码或已知拓扑模型的具体参数对比，因此难以判断新构造在纠错性能上是否优于现有方案。
