## 摘要
提升积（LP）码构成了一类重要的量子纠错码，具有有利的码参数。我们引入了一种基于群扩展和图提升的LP码族的系统构造。该构造在保持Tanner图局部结构的同时增加了码的大小，并通过链和上链映射将族内的码参数、逻辑算子和容错逻辑操作工具联系起来。作为第一个应用，我们获得了比先前报道的码参数更好的LP码。然后，我们证明了码手术工具可以通过链映射在所选的有限提升间传递，并且在若干情况下以更低的空间开销实现。我们还发展了提升簇循环码的并行积手术。最后，我们提出将提升作为为没有底层欧几里得格子的代数定义的qLDPC码定义热力学族的系统性第一步。对于几个基码和选定的提升，相干信息表现出有限尺寸交叉，而我们的结果也表明需要额外的条件来确定唯一的族。

## Abstract
Lifted product (LP) codes form an important class of quantum error correcting codes with favorable code parameters. We introduce a systematic construction of LP code families based on group extensions and graph lifts. The construction increases the code size while preserving the local structure of the Tanner graph, and relates code parameters, logical operators, and fault-tolerant logical-operation gadgets within the families through chain and cochain maps.   As a first application, we obtain LP codes with better code parameters than previously reported ones. We then demonstrate that code-surgery gadgets can be transferred across the selected finite lifts through chain maps and, in several cases, implemented with lower space overhead. We also develop parallel product surgery for lifted clustered cyclic codes. Finally, we propose lifting as a systematic first step toward defining thermodynamic families for algebraically defined qLDPC codes without an underlying Euclidean lattice. For several base codes and selected lifts, coherent information exhibits finite-size crossings, while our results also indicate that additional conditions are needed to determine a unique family.

- **研究意义**：论文提供了一套**基于群扩展和图提升**的纯代数框架，能够对任意 LP 码进行系统性进一步提升，在增大码长的同时保留基码 Tanner 图的局部结构，并通过链/上链映射建立基码与提升码之间在码参数、逻辑算子、容错逻辑操作等多个层面的联系。
- **整体含义**：该框架不仅产生了参数更优的新 LP 码实例，还为"无 Euclidean 格子的 qLDPC 码如何定义热力学族"这一基础性理论问题提供了初步探索路径。

## 2. 论文提出的方法论

### 核心数学框架

- 利用**群扩展的短正合序列**：
  $$1 \longrightarrow K \xrightarrow{\chi} H \xrightarrow{\pi} G \longrightarrow 1$$
  其中 \(K\) 为提升核，提升索引为 \(|K|\)。

### 关键构造步骤

1. **正向提升（Lift）**：给定 LP 码 \(Q\)（由经典链复形 \(A_\bullet, B_\bullet\) 在 \(RG = \mathbb{F}_2[G]\) 上取平衡积构成），通过群扩展将两个经典复形提升为 \(RH = \mathbb{F}_2[H]\) 上的复形，再取平衡积得到提升 LP 码 \(\tilde{Q}\)。选择截面 \(\sigma: G \to H\) 后，每个被支撑的群元素 \(g\) 的纤维提升由映射 \(F(\gamma, g) = \chi(\gamma)\sigma(g)\) 唯一指定。核心性质是**提升码的 Tanner 图是基码 Tanner 图的 \(|K|\)-lift**（命题 1）。
2. **投影（Projection）**：给定商同态 \(\pi: H \to G\)，通过对群代数元素逐项施加 \(\Pi: RH \to RG\)，得到投影 LP 码 \(Q^\pi\)（命题 2），并诱导出自然的**链映射与上链映射**（\(p_i\) 与 \(p^i\)）。
3. **迁移映射（Transfer maps）**：链/上链投影的对偶给出迁移映射 \(\tau_i\) 和 \(\tau^i\)，其将投影码的逻辑类映射为提升码的逻辑类——这是手术工具传递的代数基础。重要性质：
   - 当提升索引 \(t\) 为偶数时，提升得到的逻辑算子**总对易**；为奇数时保持对易/反对易关系（命题 4）。
   - 当 \(t\) 为奇数时，同调/上同调上的迁移映射**单射**、投影映射**满射**（命题 5）。
   - 奇数提升下，逻辑量子比特数满足 \(k' \ge k\)，距离满足 \(d' \le td\)；若 \(k' = k\) 则 \(d' \ge d\)（推论 6）。

### 算法流程（代码搜索）

- 搜索过程用 GAP 编程实现：对每个群扩展选择截面、选取原图（protograph）上的生成森林做**规范固定**（gauge fixing），减少核标签自由度（命题 10），然后遍历剩余赋值构造提升码并用 QDistRnd（2000 次采样）估计距离，以 \(kd^2/n\) 为优度准则筛选最优码。距离可用混合整数规划精确验证。

### 手术与热力学族的构造

- **提升码手术（lifted code surgery）**：构造一个适用于投影码 \(Q^\pi\) 的辅助码 \(A\) 和链映射 \(\Gamma_1, \Gamma_0\)，通过与迁移映射复合（\(\tilde\Gamma_i = \tau_i \circ \Gamma_i\)）将其用于提升码 \(Q\)，从而降低辅助空间开销。
- **并行积手术（PPS）**：证明在奇数提升且逻辑量子比特数保持不变时，提升 CC 码的核满足 \(\ker\tilde\partial_2 = \tau_2(\ker\partial_2)\)（命题 8），从而基码的 PPS 结构得以保留（推论 9）。
- **热力学族**：利用提升序列构造尺寸递增但仍保持基码局部结构的码族，通过相干信息（coherent information）的有限尺寸交叉分析临界行为。

## 7. 优点

- **系统性与一般性**：框架是纯代数的，适用于任意 LP 码（包括非阿贝尔群定义的情形），BB 码提升是特例，覆盖面广。
- **理论工具完整**：链/上链映射、迁移映射、同调/上同调性质的引入使逻辑算子和手术工具可以在码族内严格传递；命题 5 和推论 6 提供了清晰的参数界。

- **应用落地扎实**：码参数有实际改进；手术开销下降有明确数值支持（低速率近 2 倍）；逻辑算子表示有显式构造（如 Gross 码的 canonical 逻辑基）。

## 8. 不足与局限

- **偶数索引提升的理论缺口**：偶数 \(t\) 时迁移映射不保证单射，部分逻辑算子可能在提升后变为平凡类；作者仅给出对易/反对易关系的结论，未给出一个完整的逻辑子空间结构刻画。
- **手术距离缺少保证**：合并码距离的保持依赖随机化搜索和启发式增强，没有严格的理论证明；辅助码构造是逐步加点和边试凑出来的，不能保证对所有码都有效。
- **搜索空间仍有缩减余地**：码搜索虽经规范固定，但不同群扩展的选择众多（尤其非交换群），表中列出结果并注明"并非穷尽"，可能遗漏更优实例。
- **热力学族的判定条件不完整**：论文明确说明局部结构不足以确定唯一热力学族，但没有给出如何选择"正确的"提升分支的判定条件，仅提出了一些候选（有限半径邻域生长、内在局部性维数、Cheeger 常数等）作为未来方向。
- **有限尺寸与可靠性**：关于相干信息交叉的结论来自有限尺寸的 MCMC 模拟，没有严格的有限尺寸标度分析或理论证明；临界值的一致性宣称是初步的。
- **工程实现局限**：提升码的测量逻辑算子受限于基码逻辑算子的像空间，不能直接寻址提升码的全部逻辑算子；尽管空间开销降低，但校验权重和量子比特度有所增加，可能影响物理实现的难度。
