## 摘要
基础解码器是一类高容量神经解码器，是容错量子计算的主要候选方案，能够在大代码距离下进行准确高效的解码。然而，它们的构建通常面临陡峭的扩展障碍，因为更大的代码距离会迅速放大综合征生成和神经优化的成本。为了解决这一瓶颈，我们在此设计了神经迁移统一框架（NTU），这是一个用于高效基础解码器的统一框架。NTU的一个核心特征是它能够通过可扩展代码族共享的代数结构来对齐跨代码距离的解码任务，从而使得在较小代码上学习到的知识能够加速大规模解码器的训练。我们将NTU实例化为NTU-Transformer，这是一个基于变压器的神经解码器，专为平面表面码和双变量自行车码设计。对于电路级噪声下的平面表面码，NTU-Transformer在$[\![361,1,19]\!]$代码上优于相关性感知匹配，并进一步扩展到$[\![625,1,25]\!]$代码，通过迁移适应超越了标准匹配。对于$[\![72,12,6]\!]$的双变量自行车码，它在低物理错误率区域超越了Relay-BP。这些结果确立了我们的提议作为容错量子处理器基础解码器平摊跨距离训练的可扩展路径。

## Abstract
Foundation decoders, a class of high-capacity neural decoders, are leading candidates for fault-tolerant quantum computing, with accurate and efficient decoding at large code distances. However, their construction often faces a steep scaling barrier, as larger code distances rapidly amplify the cost of syndrome generation and neural optimization. To address this bottleneck, here we devise neural transfer unification (NTU), a unified framework for efficient foundation decoders. A central feature of NTU is its ability to align decoding tasks across code distances via algebraic structures shared by scalable code families, which enables knowledge learned on smaller codes to accelerate large-scale decoder training. We instantiate NTU as NTU-Transformer, a transformer-based neural decoder tailored for planar surface codes and bivariate bicycle codes. For planar surface codes under circuit-level noise, NTU-Transformer outperforms correlation-aware matching on the $[\![361,1,19]\!]$ code and further scales to the $[\![625,1,25]\!]$ code, where it exceeds standard matching through transfer adaptation. For the bivariate bicycle code with $[\![72,12,6]\!]$, it surpasses Relay-BP in the low-physical-error regime. These results establish our proposal as a scalable route to amortized cross-distance training of foundation decoders for fault-tolerant quantum processors.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：容错量子计算（FTQC）依赖量子纠错（QEC）保护逻辑信息，其中解码器是关键。传统解码器（如匹配解码）在大码距下计算效率下降，而神经解码器虽能学习解码规则，但早期准确率不如传统方法。**基础解码器**（如AlphaQubit系列）虽进步显著，但面临严重扩展瓶颈：训练成本随码距迅速增长（即使中等码距也需数千GPU小时），直接扩展到实际所需的大码距不切实际。
- **整体含义**：论文旨在解决基础解码器扩展到大型码距时的计算壁垒，提出一种高效的跨码距迁移学习框架，使解码知识可以从较小码距重复利用到较大码距，显著降低训练开销。

## 2. 方法论：核心思想、关键技术细节

### 核心思想：神经迁移统一框架（NTU）
- **跨码距迁移**：利用可扩展码族（如平面表面码、双变量自行车码）共享的**尺度不变性**（scale invariance）——不同码距下检测器（detector）的局部邻域结构由相同的相对位移模板定义，可跨码距复用。
- **四步流程**：
  1. **时空不变性发现**：识别码族中检测器邻域关系——由固定的相对位移集 M(x,y,t;d) 决定，不随码距改变（边界情况除外）。
  2. **距离无关的综合症编码**：将每个检测器的局部综合症模式映射为基于相对位移索引的嵌入特征，公式为 \( h(v) = \sigma\left(\sum_{u \in N(v;d)} w_{v^{-1}u} S_d(u)\right) \)，其中 \( w_{v^{-1}u} \) 是学习参数，绑定到相对位移而非绝对坐标。
  3. **神经解码**：将编码后的综合症特征输入任意神经解码器（如Transformer或图神经网络）。
  4. **迁移适应**：在较小码距训练得到参数θ*后，直接初始化较大码距的解码器（只迁移与相对位移相关的参数，重新生成距离相关的缓冲），然后在大码距数据上微调。

### 关键技术细节（NTU-Transformer实例化）
- **可扩展Transformer嵌入**：基于相对位移索引的查找表构建检测器token，保证跨码距共享同一套嵌入参数。
- **几何感知旋转位置编码（RoPE）**：使用未归一化的码坐标（如晶格坐标或代数坐标），使得相对位移产生的相位与码距无关，避免传统位置编码因码大小改变而失效。
- **逻辑读出交叉注意力**：使用可学习的逻辑查询token，通过交叉注意力从变长检测器集合中产生固定大小的逻辑错误概率预测。
- **中轮监督（Mid-round Distillation）**：在训练中，利用经典解码器对部分综合症序列生成伪标签，提供密集梯度信号，缓解冷启动问题。

## 7. 优点

- **方法论创新**：首次将跨码距迁移学习引入基础解码器训练，通过代数尺度不变性克服扩展障碍，取代传统的课程学习范式，实现更高效的平摊训练。
- **架构设计精良**：NTU-Transformer融合了基于相对位移的嵌入和几何RoPE，保证了跨码距的结构一致性，同时保持全局注意力能力。中轮蒸馏加速收敛。
- **开源性**：论文公开了完整管道和训练好的解码器，降低可复现门槛。
- **广泛的适用性**：NTU框架不限于特定神经结构（可结合Transformer、图神经网络等），可扩展到其他可扩展码族（如超图乘积码、Floquet码）。
- **实验设计严谨**：多种码族、多个码距、多个噪声水平，对比了传统和前沿神经解码器，附带消融和诊断。

## 8. 不足与局限

- **实验覆盖有限**：
  - 表面码最大测试码距为25，实际FTQC可能需要更大（如d>30）；扩展趋势尚不明确。
  - BB码仅测试了两种大小（[[72,12,6]]和[[144,12,12]]），未测试更大码距（如［288, ？, ？］）。
  - 噪声模型仅使用电路级退极化噪声，未包括实际硬件特有的噪声（如非均匀、相干噪声）。
- **算法局限性**：
  - NTU依赖于码族具有尺度不变性，对于独立优化或非结构化的码族可能不适用。
  - NTU-Transformer约3200万参数，仍较大，实时解码需要进一步压缩（如蒸馏、量化、剪枝），论文虽提及但未实现。
  - 中轮蒸馏依赖经典解码器提供伪标签，在实践中可能需额外计算资源。
- **计算资源抽象**：训练计算量报告以FLOPs和GPU小时，但未提供所有实验的总资源消耗对比，且不同硬件配置下性能可能偏差。
- **公平性考量**：Tesseract仅在小码距测试，大码距使用外推，可能不完全公平；NTU-Transformer与匹配基线相比，优势在高错误率区域较明显，但在低错误率区域（p=0.1%）匹配基线的性能未详细展示（表面码实验中p=0.3%为主）。
- **应用限制**：当前仅针对量子记忆实验，尚未扩展到逻辑电路（如逻辑门操作），解码实时性未深入评估。
