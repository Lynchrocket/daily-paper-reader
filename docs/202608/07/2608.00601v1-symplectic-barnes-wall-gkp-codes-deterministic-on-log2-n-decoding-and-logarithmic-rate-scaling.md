## 摘要
我们构造了 Barnes-Wall 格的一个显式辛实现，产生一族多模 Gottesman-Kitaev-Preskill (GKP) 码，编码速率 R = 1/2 log_2 N，并具有确定性 O(N log^2 N) 有界距离解码器。递归生成器 G_{m+1} = (G_m  0; G_m  R_m G_m)，其中 R_m = I + Ω，同时保证有效量子稳定子的辛完整性，并通过等距同构链保留精确的 Barnes-Wall 解码结构。码距恒为 Δ^2 = 1（以 2π 为单位），表示显式的距离-速率权衡，其中以非缩放保护为代价实现对数编码效率。该构造为支持非局域模连接的平台中的 GKP 纠错提供了确定性、空间高效范式。

## Abstract
We construct an explicit symplectic realization of the Barnes-Wall lattice that yields a family of multimode Gottesman-Kitaev-Preskill (GKP) codes with encoding rate $R = \frac{1}{2}\log_2 N$ and a deterministic $O(N\log^2 N)$ bounded-distance decoder. The recursive generator $G_{m+1} = \bigl(\begin{smallmatrix} G_m & 0 \\ G_m & R_m G_m \end{smallmatrix}\bigr)$ with $R_m = I + Ω$ simultaneously guarantees symplectic integrality for valid quantum stabilizers and preserves the exact Barnes-Wall decoding structure through a chain of isometric isomorphisms. The code distance is constant at $Δ^2 = 1$ (in units of $2π$), representing an explicit distance--rate tradeoff in which logarithmic encoding efficiency is achieved at the cost of non-scaling protection. This construction provides a deterministic, space-efficient paradigm for GKP error correction in platforms supporting non-local modular connectivity.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：量子纠错在连续变量（CV）系统中通过将逻辑信息编码进玻色子模式的相空间来实现。Gottesman-Kitaev-Preskill（GKP）码将稳定子定义为与格 Λ ⊂ R²ⁿ 对应的位移算子，是多模量子纠错的重要方向。
- **核心问题**：设计实用、高维的多模 GKP 分组码面临三大挑战：
  1. **速率-距离权衡**：具有增长距离的码保持恒定速率，而高速率的构造通常牺牲距离。
  2. **辛对易条件难以满足**：稠密经典格很少满足有效量子稳定子所需的辛交换条件 MᵀΩM = 2πK（K 为整反对称矩阵）。
  3. **解码计算复杂**：非结构化格上的最大似然解码需解决最近向量问题（CVP），计算代价高且在最坏情况下被推测为困难问题。
- **现有方法的不足**：
  - 拓扑方法（如 Surface-GKP 码）虽具备几何局域性，但编码率随 N 增加而消失（R ∼ O(1/√N)），且依赖最小权重完美匹配等概率图解码器，面临实时计算瓶颈。

## 2. 方法论（核心思想与关键技术细节）

### 2.1 递归生成器的构造
- **核心递归定义**：设 m ≥ 1 为递归层级，作用于 N = 2ᵐ⁻¹ 个模式（2ᵐ 维相空间），生成器递归定义为：
  - 基础情形：G₁ = I₂
  - 递归关系：G_{m+1} = [[G_m, 0], [G_m, R_m G_m]]，其中 R_m = I_{2ᵐ} + Ω_{2ᵐ}
- 关键性质：R_m/√2 同时是正交阵和辛阵且行列式为 1；R_m 本身是 √2 缩放的正交辛阵。
- 该递归结构呈现**分层蝶形网络**形态，可物理实现为辛纠缠门网络。

### 2.2 辛完整性保证（定理 1）
- 归一化重叠矩阵 K_m := G_mᵀΩ_{2ᵐ}G_m 保持整值、反对称且非奇异。
- 证明方法为归纳法：利用 Ω² = −I、Ωᵀ = −Ω 等代数关系，通过分块乘法验证所有块的整性。
- 结论：√(2π)G_m 定义有效的多模 GKP 码；所有生成子位移算符对易，形成阿贝尔稳定子群。

### 2.3 编码率与距离
- **编码率**（推论 1）：逻辑维度 D_m = det(G_m) = 2^{k_m}，其中 k_m = (m−1)2^{m−2}。编码率 R = k_m/N = (1/2)log₂N。
- **码距**：通过补充材料中证明的幺模格等价关系（Z[i] 上），码距恒为 Δ² = 1（以 2π 为单位）。
- 特别说明：GKP 码的逻辑维度由格基本胞的相空间体积决定，编码率可超过每模式一逻辑量子比特（R > 1，当 N ≥ 8 时），这不同于有限维稳定子码。

### 2.4 Minkowski 速率-距离容量界（定理 2）
- 对任意 N 模式 GKP 码，逻辑维度 D = 2^{RN}，平方距离渐近满足：Δ² ≲ (8/e)·N·2^(−R)。
- 对于常数速率码（R = O(1)），理论上限允许 Δ² ∼ O(N)；
- 本文码的 R = (1/2)log₂N 使理论上限为 Δ²_max ∼ O(√N)，而构造实际采用 O(1) 距离，这是换取确定性解码结构的有意权衡。

### 2.5 解码器的继承（附录 B，定理 4）
- 通过一系列等距同构链将原始 Barnes-Wall 解码器移植到辛对偶格 Λ⊥_SBW 上：
  - 复数映射 Φ：保持辛结构（xᵀΩy = ℑ[Φ(x)†Φ(y)]）
  - 正交阵 Ω：保持 Voronoi 胞
  - 酉阵 Q：保持欧氏解码区域（利用 Barnes-Wall 格的缩放等对偶性 Λ∗_BW = cQΛ_BW）
- 复合解码器 D_SBW⊥ 包含一次原始解码器调用和六次 O(N) 矩阵-向量乘法，总复杂度 O(N log²N)。

### 2.6 距离恒定的机制（Remark 1）
- Barnes-Wall 格的最小欧氏距离平方每次迭代严格加倍：μ(Λ_BW)² = 2^{m−1}。
- 但辛对偶缩放因子 c² = 2^{−(m−1)}，两者精确抵消，导致 GKP 码距恒为 Δ²_m = 1。
- 这是该构造独有的几何特征：递归结构压缩格堆积以编码更多逻辑量子比特，同时将对偶距离缩放到恒定值。

## 8. 不足与局限

- **码距不足**：Δ² = 1 为恒定值，不随 N 缩放，远低于 Minkowski 容量上限 O(√N)，保护能力有限。这使得该码在高噪声环境下的性能可能受限，仅适用于单模噪声方差 σ² ≲ 1/(8N) 的场景。
