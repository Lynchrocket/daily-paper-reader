## 摘要
在实用规模上实现容错量子计算需要高编码速率的量子纠错码。量子低密度奇偶校验码作为有前景的候选方案脱颖而出，特别是在中性原子阵列兴起、通过原子移动提供动态长程连接的背景下。一般而言，为量子纠错合成有效且高效的物理执行计划是一个可证明的困难组合问题，形成了随码尺寸增长而加剧的关键编译瓶颈。为克服这一复杂性，我们聚焦于具有降维特性的重要qLDPC乘积码族，并提出ONEX。该框架将复杂的二维物理执行规划分解为独立的一维子问题，每个子问题在实际编译时间内求解至最优执行深度。首先，我们通过显式的可满足性模理论编码来形式化一维执行计划。该协议产生可证明的深度最优解，并显著缩短持续时间。其次，我们开发了多阶段编译流水线，具备随时优化、移动压缩和迭代反馈功能。该流水线在保持实际墙钟时间的同时，提供渐进式优化和按需检索高质量解。第三，我们将ONEX应用于映射到中性原子阵列上的超图乘积码存储，相较于结构性一维算法和通用二维编译器，分别实现3.7倍至6.1倍和29.8倍至42.1倍的更高时钟速率，同时高效扩展到拥有2,500个数据量子比特的码。最后，我们将ONEX扩展至分区布局，揭示相关权衡的架构洞见，并通过代表性示例展示其对更广泛的提升乘积码族的适用性。

## Abstract
Achieving fault-tolerant quantum computing at a practical scale demands quantum error correction (QEC) codes with high encoding rates. Quantum low-density parity-check (qLDPC) codes emerge as a promising candidate, especially given the rise of neutral atom arrays that provide dynamic long-range connectivity via atom movements. In general, synthesizing valid and efficient physical execution plans for QEC is a provably hard combinatorial problem, forming a critical compilation bottleneck that worsens as code sizes grow. To overcome this complexity, we focus on an important product family of qLDPC codes with dimension-reduction properties, and propose ONEX. This framework decomposes complex 2D physical execution planning into independent 1D subproblems, each solved to optimal execution depth within practical compilation time. First, we formulate the 1D execution plan with an explicit satisfiability modulo theories (SMT) encoding. This protocol produces provably depth-optimal solutions with substantial duration reduction. Second, we develop a multi-stage compilation pipeline featuring anytime optimization, movement compaction, and iterative feedback. This pipeline maintains practical wall-clock times while providing progressive refinement and on-demand retrieval of quality solutions. Third, we evaluate ONEX in the application of hypergraph product (HGP) code memory mapped onto neutral atom arrays, achieving 3.7x to 6.1x and 29.8x to 42.1x higher clock rates than the constructive 1D algorithm and the general 2D compiler, respectively, while scaling efficiently to codes with 2,500 data qubits. Finally, we extend ONEX to zoned layouts, revealing architectural insights into the associated trade-offs, and demonstrate its applicability to the broader lifted-product (LP) code family through a representative example.

# 论文总结：中性原子阵列上高速率量子乘积码的架构与编译协同设计

## 1. 核心问题与整体含义（研究动机与背景）

- 容错量子计算（FTQC）依赖量子纠错码（QEC），但传统表面码的编码率随距离 \(d\) 以 \(O(1/d^2)\) 消失，导致数百万物理量子比特的巨额开销。
- 高编码率量子低密度奇偶校验码（qLDPC）码（如超图乘积码 HGP、提升乘积码 LP）具有恒定编码率和较大距离，有望将物理开销降低数量级，在约 1 万个物理量子比特级别支持实用算法。
- 中性原子阵列通过原子移动可实现动态长程连接，是执行 qLDPC 码的天然平台；但声光偏转器（AOD）控制的原子重排综合被证明为 NP 难问题，即使在一维中也是如此，成为编译瓶颈。
- 现有通用 2D 编译器（如 Enola）将重排问题拆分为布局与布线，容易陷入局部最优，导致执行时长比优化解慢数十倍；代码特化方法（如利用循环对称）无法推广到更多码族。
- **本文意义**：提出 ONEX 框架，利用乘积码结构的维度可分解性，将复杂的 2D 物理执行规划分解为独立可最优求解的 1D 子问题，实现编译复杂度从 \(O(2n^2)\) 降至 \(O(2n)\)，显著提升执行效率与容错性能。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想：结构感知的维度分解
- HGP 码由两个经典种子码通过张量积构造，其稳定子相互作用可精确分为沿行（水平）和沿列（垂直）的两组 1D 子问题，且无对角边。
- 该分解与中性原子 AOD 的行/列笛卡尔控制轴天然对齐。ONEX 将整个 2D 执行计划转化为“行阶段 + 列阶段”的正交并行 1D 执行计划，每个 1D 子问题独立求解。
- 优化对象不仅是原子重排，还包括量子比特到陷阱的映射、门调度与移动路线的联合协同优化。

### 2.2 1D 执行协议的 SMT 编码
- 输入：\(N\) 个量子比特、\(M\) 个陷阱位、\(L\) 个门阶段（由边着色得到）；输出：每个时间步的量子比特位置 \(\pi_t^q\) 和各阶段执行时间 \(t_k\)。
- 约束包括：
  1. 单射性（同一陷阱最多一个量子比特）；
  2. 门阶段顺序（\(t_k < t_{k+1}\)）；
  3. 门执行时配对量子比特共处同一相互作用点；
  4. 空闲量子比特必须占据不同相互作用点，避免串扰；
  5. 顺序保持（no-crossing）：并行移动的原子不得相互交叉，即相对顺序不变。
- 整个约束集编码为无量词位向量（QF_BV）SMT 可满足性问题，使用 Z3 求解器。
- **双向深化搜索**：向上以短超时快速探索可行深度 \(T\)（从理论下界 \(L+c\) 开始），得到可行解后向下逐步验证更小深度，直到 UNSAT 或达到下界，从而证明深度最优 \(T^*\)。

### 2.3 多阶段编译流水线
- **Phase 1：深度优化（SMT）**：获取可证明深度最优的组合拓扑。
- **Phase 2：移动压缩（MILP）**：保持 Phase 1 的排列顺序和静止模式（不改变拓扑），通过 MILP 最小化每步最大位移，再最小化总位移。该步骤避免破坏深度最优性，同时减少实际物理距离。
- **Phase 3：迭代反馈**：
  - *局部时长紧缩*：循环识别瓶颈移动，逐步收紧该步位移上界，用增量式 SMT 求解，直至收敛。
  - *全局时长紧缩*：将总时长（通过预计算查找表将非线性运动学模型离散化）编码为 SMT 上界，自适应收紧，逼近全局最优。
- **并行化覆盖**：
  - L1 种子组合：每个 SMT 调用并行运行多个随机种子，取最快结果；
  - L2 边界推测：同时探测多个候选深度/时长目标，用滑窗调度器动态剪枝，加速收敛。

### 2.4 扩展到分区架构与 LP 码族
- **分区架构（ONEX-Z）**：在存储区进行紧凑重排，并增加装载/卸载步骤在存储区与纠缠区之间穿梭量子比特。
- **LP 码推广**：将每个提升（lift）视为调度单元，分四阶段执行——提升间重排、提升内重排、门执行、方向转移（对角线驻留）与相位重复，层次化处理乘积结构。

## 6. 主要结论与发现

- **1D 执行协议**：ONEX 实现执行深度仅为 4–5 步（近常数），相比 Xu et al.（30–43 步）减少约 87%，相比 Enola（14–29 步）减少约 72%；执行时长提升 8.0–8.9 倍（vs Xu）和 4.4–8.7 倍（vs Enola）。
- **HGP 码全系统应用**：将病态提取周期缩短至个位数毫秒，时钟速率比 Xu et al. 高 **3.7–6.1 倍**，比 Enola 高 **29.8–42.1 倍**；优势随码规模增大而扩大。
- **流水线各阶段贡献**：Phase 1 提供主要收益（深度最优拓扑），Phase 2 压缩总位移 11–16%，Phase 3 局部紧缩进一步改善 17–40%；全局搜索边际收益小，说明局部策略已接近全局最优。
- **逻辑错误率**：更快的执行抑制空闲噪声，在 \(p=0.005\) 时逻辑错误率降低 1.23–1.85 倍，估计阈值提升 19.5%（从 1.26% 到 1.51%），大码受益更明显。
- **分区布局**：ONEX 优于 PM-D/ZAC-D 达 37–71 倍/9–13 倍；但 ONEX-Z 因频繁的区际穿梭开销反而比纯纠缠区 ONEX 慢 3.4–5.7 倍，揭示了“区内紧凑重排 vs 区际穿梭”之间的架构权衡。
- **LP 码扩展**：对 \([[2610,744,d\le16]]\) LP 码给出可执行框架，ONEX-Z 比 ONEX 总时长节省约 10%，说明在门密度较低时分区架构可能有利。

## 7. 优点

- **结构驱动的维度分解**：将 NP 难的 2D 问题化简为正交的 1D 子问题，实现了可证明的最优深度，并大幅降低编译复杂度。
- **形式化方法的高质量解**：SMT 编码保证深度最优，MILP 进一步压缩位移，迭代反馈兼顾局部与全局，解质量远超启发式基线。
- **协同设计视角**：同时优化量子比特映射、移动计划和门调度，而非孤立地处理单一环节。
- **完备的工程化流水线**：包含 anytime 求解、并行化组合、增量求解、进度可监控，使得大规模离线编译具备实践可行性。
- **评估深入**：对执行深度、时长、时钟速率、逻辑错误率、编译时间、收敛行为均做了全面分析，并通过消融实验分解各阶段贡献。
- **可推广性**：不仅覆盖 HGP 码，还扩展到分区架构和 LP 码族，显示了方法的通用性。

## 8. 不足与局限

- **适用范围受限**：方法依赖乘积码（HGP/LP）的外积结构；对不具类似分解性质的一般 qLDPC 码无法直接应用。
- **编译时间仍较长**：SMT 求解本质指数增长，\(N=91\)（约 4,225 量子比特）的编译需 17.6 小时；虽然属于一次性离线任务，但进一步发展仍受限于 NP-hard 本质。
- **物理模型简化**：空闲噪声采用线性近似，运动学模型仅考虑最大位移与加速度，未计及原子加热、潜在串扰、转移失败等真实硬件效应；未在真实中性原子系统上验证。
- **分区实验不完整**：单轮电路、固定穿梭策略，未评估多轮病态提取下的动态布局优化；未定量分析穿梭对保真度的影响。
- **LP 码结果可信度**：案例研究基于手写四阶段框架的性能估算，未给出完整编译流水线的实际求解时间与仿真验证，结论尚属初步。
- **实验对照细节**：Enola 等基线可能未针对本任务的 1D 子问题

实验对照细节：Enola 等基线可能未针对本任务的 1D 子问题进行专门调优，其内部抽象与调度策略面向通用 2D 布局，在投射到 1D 场景时可能无法发挥最佳性能，导致对比结果在一定程度上偏向 ONEX。此外，所有评估均基于模拟，缺少真实中性原子平台上的端到端验证，编译与执行的实际可行性仍需实验确认。

## 9. 总结与展望

ONEX 的核心贡献在于揭示并利用乘积码的维度可分解性，将原本棘手的 2D 原子阵列编译任务拆解为可证明最优的 1D 子问题，从而在高编码率 qLDPC 码的物理执行上取得了数量级的性能提升。该工作不仅提供了高效的编译框架，还建立了“码结构—硬件控制—编译优化”三者协同设计的范例，对未来基于中性原子的容错量子计算架构具有重要指导意义。

然而，当前结果仍停留在模拟阶段，编译时延与物理模型的简化也限制了其直接实用。后续工作可沿以下方向推进：一是将 ONEX 推广到更一般的图结构码或随机 qLDPC 码，探索近似分解策略；二是引入更精细的物理噪声与运动学模型，提高性能预测的可信度；三是与实时控制实验结合，验证编译方案在真实硬件上的正确性与鲁棒性；四是进一步优化 SMT 求解效率，借助领域专用剪枝、增量求解与启发式种子技术，将编译时间压缩至可接受的在线或近在线水平。

总体而言，ONEX 以优雅的数学分解与严谨的形式化方法，显著推进了高码率量子纠错码在可扩展中性原子平台上的落地进程，是量子架构与编译协同设计领域一份高质量、高影响力的研究成果。
