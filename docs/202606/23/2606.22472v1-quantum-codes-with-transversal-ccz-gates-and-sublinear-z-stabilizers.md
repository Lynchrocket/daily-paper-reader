## 摘要
我们构造了具有横向CCZ门的量子CSS码，其Z稳定子允许次线性权重的生成集。我们建立在Guruswami和Golowich的代数打孔框架上，该框架将具有所需Schur积和距离条件的经典码转化为具有横向CCZ的CSS码。然而，将该框架直接应用于代数扩展器码会遇到其小对偶距离的问题，因此仅产生次线性量子维度。我们的主要技术步骤是一个精炼的打孔定理，其中全局对偶距离假设被替换为仅对所选取的打孔集的条件。将该定理应用于代数扩展器码，对于每个固定的m≥3，得到显式的增长字母表CSS码，参数为[[N, Θ(N), Ω(N^{1/m})]]，且具有横向CCZ门。此外，Z稳定子空间具有权重为O(N^{1/m})的显式生成集。我们还使用乘法友好码的射影重数版本将字母表减小到固定的素域。得到的长度为n的固定素域CSS码三元组仍然具有横向CCZ门。其维度接近线性，距离为n^{1/m}（忽略多对数因子），而Z稳定子局部性仍然是次线性的，同样忽略多对数损失。

## Abstract
We construct quantum CSS codes with transversal \(CCZ\) gates whose \(Z\)-stabilizers admit sublinear-weight generating sets. We build on the algebraic puncturing framework of Guruswami and Golowich \cite{GG24}, which turns classical codes with the required Schur-product and distance conditions into CSS codes with transversal \(CCZ\). However, applying the framework directly to the algebraic expander codes of \cite{KT26} runs into their small dual distance, and therefore produces only sublinear quantum dimension. Our main technical step is a refined puncturing theorem in which the global dual-distance assumption is replaced by a condition only on the selected puncturing set. Applying this theorem to algebraic expander codes gives explicit growing-alphabet CSS codes with parameters \([[N,Θ(N),Ω(N^{1/m})]]\), for every fixed \(m\geq 3\), and with transversal \(CCZ\) gates. Moreover, the \(Z\)-stabilizer space has an explicit generating set of weight \(O(N^{1/m})\). We also reduce the alphabet to a fixed prime field using a projective-multiplicity version of multiplication-friendly codes. The resulting fixed-prime-field CSS code triples, of length \(n\), still have transversal \(CCZ\) gates. Their dimension is near-linear, their distance is \(n^{1/m}\)   up to polylogarithmic factors, and the \(Z\)-stabilizer locality remains sublinear, again up to polylogarithmic losses.
