## 摘要
我们引入了一个约当标准型框架，用于从 $\mathbb{F}_{q^2}$ 上的任意经典线性码构造 $q$ 元量子稳定子码。该框架不要求经典线性码 $\mathcal{C}$ 满足对偶包含条件（即自正交性）。给定经典码 $\mathcal{C}=[n,k,d]_{q^2}$，其校验矩阵为 $H$，我们用秩 $r=(n-k)-\dim_{\mathbb{F}_{q^2}}(\mathcal{C}^{\perp_h}\cap \mathcal{C})$ 度量厄米自正交的障碍。成分码 $\mathcal{C}$ 是 $r$-近对偶包含的，或者等价地，$\mathcal{C}^{\perp_h}$ 是 $r$-近自对偶的，这意味着 $r=\Rank(HH^{\dagger})=\dim_{\mathbb{F}_{q^2}}(\mathcal{C}^{\perp_h})-\dim_{\mathbb{F}_{q^2}}(\mathcal{C}^{\perp_h}\cap \mathcal{C})$。通过沿分解 $A=PJ_AP^{-1}$ 的约当基 $W=P^{-1}$ 进行秩1扰动，系统降低厄米内积矩阵 $A=HH^{\dagger}$ 的秩，我们构造了一个显式的厄米自正交码 $\mathcal{C}_{\mathrm{so}}=[n+r,n-k]_{q^2}$。一个充分距离保持准则保证得到的 $q$ 元量子码的参数为 $[[n+r,2k-n+r,\geq d]]_q$。将此构造应用于经典码，产生了若干创纪录的量子码，这些码改进或补充了Grassl表中最佳已知参数。

## Abstract
We introduce a Jordan-canonical-form framework for constructing $q$-ary quantum stabilizer codes from arbitrary classical linear codes over $\F_{q^2}$. The framework does not require the classical linear code $\mathcal{C}$ to satisfy the dual-containing condition (i.e., self-orthogonality). Given a classical code $\mathcal{C}=[n,k,d]_{q^2}$ with parity-check matrix $H$, we measure the obstruction to Hermitian self-orthogonality by the rank $r=(n-k)-\dim_{\F_{q^2}}(\mathcal{C}^{\perp_h}\cap \mathcal{C})$. The ingredient code $\mathcal{C}$ is $r$-nearly dual containing, or, equivalently, $\mathcal{C}^{\perp_h}$ is $r$-nearly self-orthogonal, by which we mean that $r=\Rank(HH^{\dagger})=\dim_{\F_{q^2}}(\mathcal{C}^{\perp_h})-\dim_{\F_{q^2}}(\mathcal{C}^{\perp_h}\cap \mathcal{C})$. By systematically reducing the rank of the Hermitian inner-product matrix $A=HH^{\dagger}$ through rank-one perturbations along the Jordan basis $W=P^{-1}$ of the decomposition $A=PJ_AP^{-1}$, we construct an explicit Hermitian self-orthogonal code $\mathcal{C}_{\mathrm{so}}=[n+r,n-k]_{q^2}$. A sufficient distance-preservation criterion guarantees that the resulting $q$-ary quantum code has parameters $[[n+r,2k-n+r,\geq d]]_q$. Applying this construction to classical codes produces several record quantum codes that improve or supplement the best-known parameters in Grassl's tables.

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：用秩 $r = \Rank(HH^\dagger)$ 度量经典码偏离Hermitian自对偶的程度，称为“ $r$-近自对偶”。通过向校验矩阵 $H$ 追加 $r$ 个精心选择的列向量，逐步将 $A$ 的秩降至0，从而得到自正交码。

- **关键技术细节**：
  - **Hermitian内积矩阵分解**：计算 $A = HH^\dagger \in \mathbb{F}_{q^2}^{(n-k)\times(n-k)}$，并得到其Jordan标准形 $A = P J_A P^{-1}$。取 $W = P^{-1}$ 的列组成Jordan基。
  - **迭代秩-1降秩**：利用定理III.5（一般秩-1减性），存在向量 $u$ 使得 $\Rank(A+uu^\dagger) = \Rank(A) - 1$。具体地，从Jordan基中选取满足“活跃条件” $Aw_j \neq 0$ 的列 $w_j$，构造 $u = k v_1$（其中 $v_1$ 来自 $A$ 的秩-1分解，$k$ 满足 $k^{q+1} = -c_1$），则 $uu^\dagger = -B_1$ 可消去一个秩-1分量。
  - **距离保持准则（定理III.9）**：要求扩展向量 $w_j$ 同时满足：(C1) 活跃条件 $Aw_j \neq 0$；(C2′) 零空间距离条件 $\operatorname{d}(\operatorname{NullSpace}(H_S^{(q)})) \geq d-1$，其中 $S = \operatorname{supp}(w_j)$。该准则充分保证扩展后对偶码最小距离不变。
  - **完整构造流程**：
    1. 输入经典码 $\mathcal{C}=[n,k,d]_{q^2}$ 的校验矩阵 $H$。
    2. 计算 $A=HH^\dagger$，$r = \Rank(A)$。
    3. 迭代 $i=1,\dots,r$：
        - 对当前 $A_i$ 做Jordan分解，提取 $W_i=P_i^{-1}$。
        - 按权重递增顺序扫描 $W_i$ 各列，选取满足 (C1) 和 (C2′) 的向量 $w^{(i)}$。
        - 增广 $H_{i} = [H_{i-1} \mid w^{(i)}]$，更新 $A_i = H_i H_i^\dagger$。
    4. 得到自正交码 $\mathcal{C}_{\mathrm{so}} = [n+r, n-k]_{q^2}$（生成矩阵为 $H_r$）。
    5. 应用Hermitian构造 ⟹ 量子码 $[[n+r, 2k-n+r, \ge d]]_q$。
