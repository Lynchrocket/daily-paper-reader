## 摘要
中性原子量子计算机是容错量子计算的一个有前景的平台，但逻辑性能取决于综合征提取期间的系统性实际噪声因素。在双同位素Yb阵列中，数据量子比特和辅助量子比特的角色在光谱上分离，允许辅助量子比特原位测量，无需额外的输运或搁置操作。在这里，我们量化了双同位素Yb架构用于表面码存储器的优势。我们使用广义泡利扭曲为双同位素171Yb-174Yb系统开发了一个实验驱动的Clifford兼容噪声模型，并将其实现为Stim的包装器，称为DualYbSim，已打包为开源Python库。对旋转和XZZX表面码的模拟表明，具有原位测量的双同位素架构在所考虑的架构中实现了最低的逻辑错误率，优于基于搁置或分区测量的单同位素方案。我们的误差预算分析还确定里德伯态衰变是主要限制因素，贡献了逻辑错误率缩放的74-80%，突出了改进FTQC性能的具体实验目标。

## Abstract
Neutral-atom quantum computers are a promising platform for fault-tolerant quantum computation, but logical performance depends on systemic realistic noise factors during syndrome extraction. In dual-isotope Yb arrays, the roles of data and ancilla qubits are separated spectrally, allowing ancilla qubits to be measured in place without additional transport or shelving operations. Here we quantify the advantage of a dual-isotope Yb architecture for surface code memories. We develop an experimentally motivated Clifford-compatible noise model for dual-isotope 171Yb-174Yb systems using generalised Pauli twirling and implement it as a wrapper for Stim called DualYbSim, which has been packaged as an open source Python library. Simulations of rotated and XZZX surface codes show that a dual-isotope architecture with in-place measurement achieves the lowest logical error rates among the architectures considered, outperforming single-isotope schemes based on shelving or zoned measurement. Our error-budget analysis also identifies Rydberg-state decay as the dominant limitation, contributing to 74-80% of the logical error rate scaling, highlighting concrete experimental targets for improving FTQC performance.

### 2. 论文提出的方法论

- **核心思想**：构建一个实验驱动的、Clifford 可模拟的噪声模型，将中性原子系统中复杂的多能级非 Pauli 噪声映射为 Pauli 错误通道与擦除通道的组合，从而利用高效的稳定子模拟器进行大规模 QEC 仿真。
- **关键技术细节**：
  - **双同位素量子比特编码**：
    - **数据量子比特**（¹⁷¹Yb）：两种方案——基态核自旋编码（g-qubit）和亚稳态 ³P₀ 编码（m-qubit）。
    - **辅助量子比特**（¹⁷⁴Yb）：光钟量子比特（|0⟩ = ¹S₀，|1⟩ = ³P₀）。
  - **广义 Pauli Twirling 近似（GPTA）**：将包含计算子空间与损耗态的多能级噪声通道分解为：
    - 一个 Pauli 错误通道（作用于计算子空间内），误差概率为 \( \tilde{E}_{\text{twirl}} \)
    - 一个擦除通道（表示向非计算子空间的不可逆跃迁），误差概率为 \( E_{\text{erase}} \)
    - 组合形式为 \( \mathcal{E}_{\text{error}} \approx \mathcal{E}_{\text{erase}} \circ \tilde{\mathcal{E}}_{\text{twirl}} \)
  - **噪声通道分类**：涵盖相干控制（单比特门、双比特门、钟跃迁激发）、测量、重置、空闲、衰变、输运六类噪声源，每个通道均通过 Kraus 算子显式定义（附录 A）。
  - **完整噪声模型封装**：命名为 **DualYbSim**，以 Stim 的包装器形式实现，作为开源 Python 库公开提供。
  - **量子纠错码**：
    - 旋转表面码（rotated surface code）：标准 CSS 码，X/Z 型稳定子按棋盘格划分。
    - XZZX 表面码：非 CSS 变体，所有面为同一种格式的稳定子生成元 \( S_f = X_{v_{nw}} \otimes Z_{v_{ne}} \otimes Z_{v_{sw}} \otimes X_{v_{se}} \)。
  - **综合征提取（SE）方式**：
    - **正常 SE（Normal SE）**：标准稳定子测量电路，采用 Z/N 门序以最小化 hook 错误。
    - **SWAP SE**：结合量子态 SWAP 门与物理原子位置交换，实现数据量子比特的定期刷新；在不增加纠缠门数量的前提下实现（利用 CZ 门抵消与经典控制 Z 门吸收）。
  - **三种测量架构**：
    - **原位测量（In-place）**：双同位素专属，利用光谱隔离抑制读出串扰。
    - **搁置测量（Shelving）**：单同位素中，通过将未测量量子比特转移到离共振的亚稳态来避免荧光。

### 6. 论文的主要结论与发现

1. **双同位素架构最优**：(¹⁷¹Yb-g, ¹⁷⁴Yb) 双同位素配置 + 原位测量 + 正常 SE 在所有配置中取得最低的逻辑错误率（LER），且错误抑制因子最高。
2. **XZZX 码普遍优于或持平旋转表面码**：对于单同位素配置，XZZX 码的 LER 约为旋转表面码的一半（d = 21 时）；对于双同位素配置两者几乎一致。
3. **¹⁷¹Yb-g 优于 ¹⁷¹Yb-m**：m-qubit 受亚稳态到基态衰变（DECAY_mg）影响，性能较差；若引入擦除转换技术可能改善，但需额外开销。
4. **SWAP SE 不如正常 SE**：与以往研究的预期相反，在 Yb 系统中 SWAP SE 引入的额外门操作错误超过了原子刷新带来的收益（未利用擦除信息时）。
5. **Rydberg 态衰变是主要错误源**：贡献了逻辑错误率缩放的 **74–80%**，其中 DECAY_rg（向基态衰变）和 LOSS_r（向损耗态衰变）各占约 30–40%。
6. **降低 Rydberg 衰变的收益大于降低去极化误差**：
   - 将 Rydberg 衰变率减半可使 \( \Lambda^{-1} \) 从 0.54 降至 0.32，即错误抑制速度提升约 **1.7 倍**。
   - 即使完全消除 Rydberg 衰变贡献，双同位素配置的剩余误差贡献仍然最低，说明其优势具有稳健性。
7. **可操作目标**：将双比特门时间缩短约 20 倍（至约 15 ns）可使 Rydberg 衰变贡献降至与其他误差源可比水平，可通过更高功率脉冲激光实现。
