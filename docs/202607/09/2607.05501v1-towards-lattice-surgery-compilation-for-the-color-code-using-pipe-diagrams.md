## 摘要
管道图已成为表面码中灵活的晶格手术编译和时空优化的强大框架。相比之下，用于色码架构的类似编译技术仍 largely 未被探索，尽管色码具有减少量子比特开销和横向单比特 Clifford 门等有利特性。在这项工作中，我们为 6.6.6 晶格上的三角形色码开发了一种管道图表示，并建立了其与计算 ZX 图解描述之间的对应关系。我们提出了与距离无关的色码管道图构造，以及关联曲面、稳定子和症状提取电路的显式实现。该框架实现了逻辑计算在时空中的宏观优化，以及可执行症状提取电路的微观编译。我们展示了利用色码几何实现紧凑时空嵌入的潜力。这些结果为色码架构中的自动晶格手术编译和图解优化奠定了基础。

## Abstract
Pipe diagrams have emerged as a powerful framework for flexible lattice surgery compilation and spacetime optimization for the surface code. In contrast, analogous compilation techniques for color code architectures remain largely unexplored, despite the color code's favorable properties, including reduced qubit overhead and transversal single-qubit Clifford gates. In this work, we develop a pipe diagram representation for the triangular color code on the 6.6.6 lattice and establish its correspondence to ZX-diagrammatic descriptions of computation. We present distance-independent constructions of color code pipe diagrams together with explicit realizations of correlation surfaces, stabilizers, and syndrome extraction circuits. This framework enables both macroscopic optimization of logical computations in spacetime and microscopic compilation to executable syndrome extraction circuits. We demonstrate the potential for compact spacetime embeddings with the color code's geometry. These results provide a foundation for automated lattice surgery compilation and diagrammatic optimization in color code architectures.

- **核心思想**：采用 6.6.6 晶格上的三角形色码，通过半透明 domain walls（STDWs）进行晶格手术；构建与距离无关的管道图表示，并与 ZX 图建立对应关系，从而实现基于图规则的空间-时间优化。
- **关键技术细节**：
  - **管道图原语**：
    - **独立棱柱（standalone prism）**：表示单色码补丁的内存实验，底面和顶面颜色代表初始化/测量基（红 = X，蓝 = Z），垂直面无颜色（因 X/Z 逻辑算子均可终止于任意边界）。
    - **垂直管道（vertical pipe）**：连接时间方向上的棱柱，默认采用“星形”逻辑算子代表。
    - **水平管道（horizontal pipe）**：表示通过 STDW 合并/分裂补丁的操作，水平管道垂直壁有颜色（红表示 X 型 domain wall），水平面颜色指示中间测量。
  - **关联曲面（correlation surfaces）**：
    - 垂直关联曲面：通过反射“星形”算子生成，保证通过 domain wall 的任意子性质；必须延伸穿过整个结构。
    - 水平关联曲面：通过选择稳定子子集 CS_X（该子集乘积在逻辑算子处非平凡，在其余位置平凡）构造；需要区分 bulk 补丁和边界补丁，并考虑 STDW 的颜色和权重-2 稳定子。
  - **ZX 图对应**：
    - 管道图中蓝色/红色节点对应蓝色/红色 ZX 节点；节点度数最高可达 5（表面码为 4），可直接嵌入时空。
    - 通过 π-copy、spider fusion、identity removal 等 ZX 规则可进行等效变换，实现时空体积缩减。
  - **全 Clifford 门集**：
    - 单比特 Clifford 门（H, S）可通过横向物理门在时间方向上执行，表示为管道图中黑色平面，无额外空间开销。
    - 空间 Hadamard 门可通过混合型稳定子实现，但会复杂化 ZX 对应，故本文主要采用时间方向执行。
  - **症候提取电路**：
    - 双型稳定子采用“超密”（superdense）方案：每个 plaquette 用两个辅助 qubit，一次 Bell 对制备/拆解即可测量 X 和 Z。

### 6. 论文的主要结论与发现

- **管道图框架可行**：首次为 6.6.6 晶格三角形色码建立了 distance-independent 的管道图表示，并能对应到 ZX 图。
- **空间-时间优化潜力**：通过 ZX 图规则可显著缩减时空体积（如 3 个 CNOT 从 naive 的 16 或 18 降至 6），且色码的更高度数节点（最多 5）可直接嵌入，可能进一步节省。

### 7. 优点

- **开创性**：首次将管道图从表面码扩展到色码，填补了色码自动化编译框架的空白。
- **层次化编译**：同时支持宏观（ZX 图级优化）和微观（具体稳定子与症候提取电路）编译，思路清晰。
- **距离无关表示**：关键构造（管道图、关联曲面）不依赖具体距离，便于不同规模下的复用。
- **紧凑嵌入潜力**：由于色码几何特性（三边界、星形算子、更高节点度数），可实现比表面码更紧凑的时空表示（如横向 Clifford 门、多 CNOT 优化）。
- **症候提取方案可组合**：超密方案与内联折叠可交错执行，仅常数时间开销，保证了整体效率。

### 8. 不足与局限

- **解码器瓶颈**：色码解码问题仍较困难，本文使用的 tesseract 解码器性能不如表面码的 pymatching，导致直接比较不公平，且高距离下性能未知。
