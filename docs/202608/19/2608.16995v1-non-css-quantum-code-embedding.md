## 摘要
我们将[Phys. Rev. A 113, 022438 (2026)]中的统一框架推广到任意稳定子码（为强调称为非CSS码）。这一推广在逻辑测量、量子权重约简和欧几里得嵌入等领域具有直接的影响。例如，目前基于（高度1）锥体的CSS（纯$X,Z$型）逻辑测量已被充分理解，而非CSS（如$Y$型）逻辑测量则是特设的（例如依赖局部Clifford变换）。类似地，量子权重约简和最优欧几里得嵌入仅对CSS输入码存在。在此，我们表明我们的推广框架解决了这一问题，因此许多构造，包括qLDPC手术、Layer Codes和量子权重约简，都以相对直接的方式推广到非CSS码。为清晰起见，我们详细推导了前述例子。

## Abstract
We generalize the unified framework in [Phys. Rev. A 113, 022438 (2026)] to accommodate arbitrary stabilizer codes (referred as non-CSS for emphasis). The generalization has immediate consequences in areas including logical measurement, quantum weight reduction and Euclidean embedding. For example, currently CSS (pure $X,Z$-type) logical measurements are well-understood based on the (height-1) cone, while non-CSS (e.g., $Y$-type) logical measurements are ad hoc (e.g., rely on local Clifford transform). Similarly, quantum weight reduction and optimal Euclidean embeddings only exist for CSS input codes. Here, we show that our generalized framework addresses this issue, and thus many constructions, including qLDPC surgery, Layer Codes and quantum weight reduction generalize to non-CSS codes in a relatively straightforward fashion. The previously mentioned examples are derived in detail for clarity.
