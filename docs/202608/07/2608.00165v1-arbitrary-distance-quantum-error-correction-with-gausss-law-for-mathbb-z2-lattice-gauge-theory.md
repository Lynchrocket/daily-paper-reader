## 摘要
Rajput、Roggero和Wiebe先前已经证明，$\mathbb Z_2$高斯定律约束可用于构建对任意单量子比特错误鲁棒的高效量子纠错码（QECC）。在本工作中，我们将该构造推广为对任意$t$量子比特错误鲁棒，其中$t$为任意正整数。这包括通过在给定码距下最小化所需物理量子比特数量，推导出所考虑族内的最优高斯定律码。最后，我们在物理量子比特数量、编码哈密顿量的局域性以及码容量设置下的逻辑错误率等指标上，将我们的码与其他高效QECC进行比较。与对每个格点自由度使用领域无关码相比，我们发现高斯定律码主要擅长降低编码哈密顿量的局域性。此外，对于$t \le 3$（码距$d \le 7$），物理量子比特开销也得到降低。

## Abstract
It has previously been shown by Rajput, Roggero, and Wiebe that $\mathbb Z_2$ Gauss's law constraints can be used to build efficient quantum error-correcting codes (QECCs) that are robust against arbitrary single-qubit errors. In this work, we generalize the construction to be robust against arbitrary $t$-qubit errors, where $t$ is any positive integer. This includes a derivation of the optimal Gauss's law code within the considered family by minimizing the number of physical qubits required for a given code distance. Finally, we compare our codes against other efficient QECCs on metrics such as the number of physical qubits, the locality of the encoded Hamiltonian, and the logical error rate in the code capacity setting. Compared to using a domain-agnostic code for every lattice degree of freedom, we find that the Gauss's law code primarily excels at reducing the locality of the encoded Hamiltonian. Moreover, the physical qubit overhead is also reduced for $t \le 3$ (distance $d \le 7$).

## 二、方法论：核心思想与技术细节

### 1. 构造框架概览
论文采用**两步构造法**：

- **第一步**：构建"经典高斯定律码"（Classical Gauss's law code），负责处理比特翻转（$X$型）错误，支持任意码距。
- **第二步**：将该经典码与一个相位翻转（$Z$型）内码进行**串接（concatenation）**，得到完整的量子高斯定律码 $C_{\text{out}} \circ C_{\text{in}}$，同时纠正 $X$ 和 $Z$ 错误。

### 2. 经典高斯定律码的构造
- **基本思想**：将格点上的每个格点变量（site）和链接变量（link）进行**多次复制（duplication）**，然后结合高斯定律约束和复制变量之间的奇偶校验作为线性约束。
  - 记格点 $S_n$ 复制 $p_n$ 次，链接 $L_{n,\mu}$ 复制 $q_{n,\mu}$ 次。
  - 每个格点 $n$ 处的约束为：
    $$S_n^{(a)} + \sum_{\mu=1}^{D} \left( L_{n,\mu}^{(b_\mu)} + L_{n-\hat{\mu},\mu}^{(c_\mu)} \right) = 0$$
    对任意副本索引 $a, b_\mu, c_\mu$ 均成立。

- **逻辑自由度守恒验证**：虽然复制增加了物理比特数，但独立约束数也随之增加，最终逻辑比特数恒等于原始 $DN$ 个链接变量数，不引入额外逻辑自由度。这一性质被严格证明。

- **码距的物理图像**：经典高斯定律码的最小权重逻辑错误对应于格点上的**通量弦激发**（flux string）：
  - **开弦**：一对物质激发由电通量路径连接，权重 $= p$（两端格点）+ $\sum q$（路径上链接）。
  - **闭弦**：闭合电通量回路，权重 $= \sum q$（路径上链接）。
  - 码距 $d = \min(w_o, w_c)$，即所有可能开弦和闭弦的最小权重。

### 3. 最优编码率推导
论文推导了**在给定码距 $d$ 下最小化物理量子比特数 $n$** 的最优复制模式，即最优编码率 $k/n$：

**1D情形（定理III.5）**：
- 上界：$\dfrac{k}{n} \le \dfrac{2}{d(d+1)}$
- 最优构造：所有链接 $q_n = 1$，格点复制数按奇偶子格选取：
  $$p_n = \begin{cases} \lceil (d-1)/2 \rceil, & n \equiv 0 \pmod 2 \\ \lceil d/2 \rceil - 1, & n \equiv 1 \pmod 2 \end{cases}$$
- 最优码参数为 $[\![ Nd(d+1)/2, \, N, \, d ]\!]$。

**2D情形（定理III.6）**：
- 编码率上界（分情况）：
  - $d = 3$：$\dfrac{k}{n} \le \dfrac{2}{9}$
  - $d > 3$ 且 $d$ 为偶数：$\dfrac{k}{n} \le \dfrac{16}{7d^2}$
  - $d > 3$ 且 $d$ 为奇数：$\dfrac{k}{n} \le \dfrac{16}{(7d+1)d}$
- 最优构造利用**格点奇偶子格**（$S_1, S_2$）和**链接四分组**（$L_1, L_2, L_3, L_4$，按方向和横坐标奇偶性划分）的分区，对每个子集独立赋予复制数。每个方格恰好包含来自各链接组的一条链接，使码距控制成为可能。

### 4. 量子码的串接构造
- 经典高斯定律码 $C_{\text{out}} = [n_{\text{out}}, k_{\text{out}}, d_{\text{out}}]$ 与外码角色；相位翻转码 $C_{\text{in}} = [d, 1, d]$（经典重复码）作为内码。
- 量子码参数为 $C_{\text{out}} \circ C_{\text{in}} = [\![n_{\text{out}} d, \, k_{\text{out}}, \, \min(d_{\text{out}}, d) ]\!]$。
- 该构造保证生成**量子低密度奇偶校验码（QLDPC）**，即稳定子权重和每个量子比特上的稳定子数量都与晶格尺寸 $N$ 无关。

### 5. 纠错解码方法
- 使用**最大似然解码（MLD）**，利用串接结构实现高效的**后验概率评估**（消息传递式的分层解码）。
- 对于Z记忆（Z memory）任务，使用边缘化ML解码，寻找最优 $x_L$；对于X记忆（X memory）任务，边缘化 $x_L$ 寻找最优 $z_L$。
- 在退极化噪声下，推导了Z/X记忆实验的显式解码规则；对于不相关X/Z噪声，给出了解析可处理的显式解码器。

## 六、主要结论与发现

### 1. 物理量子比特开销
- 在1D和2D中，最优高斯定律码在**低码距（$d \le 7$，即 $t \le 3$）时物理量子比特数少于最小长度码**，推广了RRW在 $d=3$ 时的发现。
- 高斯定律码开销随码距按 $O(d^2)$ 增长，而最小长度码按 $O(d)$ 增长，因此**在 $d \ge 9$（1D）或 $d \ge 9$ 附近（2D）出现交叉**，此后高斯定律码不再具有量子比特数优势。

### 2. 哈密顿量局域性
- **高斯定律码的核心优势体现在降低编码哈密顿量的局域性**：
  - 1D硬核玻色子情形：局域性为 $2t+1$，是最小长度码（$6t+3$）的**约1/3**。
  - 1D交错费米子情形：局域性为 $6t+1$，仍优于 $6t+3$。
  - 2D硬核玻色子情形：局域性为 $2t+1$，最小长度码为 $8t+4$，改进约**4倍**（$d \ge 5$）。

### 3. 逻辑错误率
- **退极化噪声下（Z记忆）**：$d=3$ 时高斯定律码优于最小长度码，但 $d=7$ 时关系反转。
- **退极化噪声下（X记忆）**：高斯定律码在所有 $d=3,5,7$ 下逻辑错误率都**低于**最小长度码；且高斯定律码的阈值交叉点更高。
- **不相关X/Z噪声下（最坏情况LER）**：高斯定律码在 $d=3$ 时更优，但 $d=5$ 和 $d=7$ 时反被最小长度码超越。
- 高斯定律码能够正确检测并纠正**规范破坏错误**（如单格点翻转），这类错误对最小长度码是逻辑错误。

### 4. 核心理论贡献
- 给出了1D和2D最优高斯定律码的**精确编码率上界**和**显式饱和构造**。

### 性能局限
1. **量子比特缩放劣势**：高斯定律码 $O(d^2)$ 的物理量子比特增长意味着它不适用于大码距场景——这是一个根本性的扩展性限制。
2. **逻辑错误率表现不一致**：在Z记忆和部分噪声模型下，码距增大后高斯定律码的表现被最小长度码反超，说明该码**并非在所有场景下都最优**。
3. **X/Z记忆性能不对称**：原因可能与串接结构（相位翻转和比特翻转被内外码分别处理）以及逻辑算子权重（式IV.11）有关，这种不对称性在通用QECC中不常见。

### 其他局限
1. **未考虑门操作**：容错量子门操作（逻辑CNOT等）的具体实现和成本未被分析（仅提及RRW已有 $d=3$ 方案的参考）。
2. **仅限阿贝尔规范群**：扩展到非阿贝尔规范理论仍是将来的工作。
3. **通用性受限**：最优构造的推导依赖于关于格点尺寸（$N_\mu$ 偶数、$N_\mu \ge d$）的简化假设。
4. **哈密顿量局域性评估的简化**：仅以作用权重作为模拟难度的代理指标，未评估具体容错架构下的门成本和电路深度。
