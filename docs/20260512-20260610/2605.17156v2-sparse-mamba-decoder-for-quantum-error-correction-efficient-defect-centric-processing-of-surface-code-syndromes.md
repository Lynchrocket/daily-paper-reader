## 摘要
量子纠错（QEC）对于构建容错量子计算机至关重要，需要同时具备准确性、快速性和可扩展性的解码器。大多数最先进的神经解码器能实现高精度，但无论实际错误率如何，都会处理大小为$O(d^2 R)$的完整稠密征候阵列，其中$d$是码距，$R$是测量轮数。在物理相关的错误率（p ~ 0.1%）下，少于5%的征候条目包含活跃检测事件——然而现有解码器处理整个征候体。我们引入稀疏Mamba解码器（SMD），一种缺陷中心的神经解码器，它仅处理k个活跃检测事件，每个缺陷使用13维特征表示，并采用Mamba状态空间骨干，实现了$O(k)$复杂度。在退极化、均匀电路级、SI1000和Google Sycamore实验基准测试中，SMD在SI1000噪声下将$d \le 5$的MWPM逻辑错误率降低多达49%，运行速度比Tesseract近MLD解码器快95-467倍，比Belief Matching快232-463倍，并在均匀电路级噪声下对d=3-9保持几乎恒定的延迟（24-57微秒）。在Sycamore实验数据集上，SMD集成匹配或略优于Varbanov等人的稠密Mamba解码器。所有结果均在商用NVIDIA GPU上获得，参数量为7.5-1600万，无需专用加速器。

## Abstract
Quantum error correction (QEC) is essential for building fault-tolerant quantum computers, requiring decoders that are simultaneously accurate, fast, and scalable. Most state-of-the-art neural decoders achieve high accuracy but process the full dense syndrome array of size $O(d^2 R) $regardless of the actual error rate, where d is the code distance and R is the number of measurement rounds. At physically relevant error rates (p ~ 0.1%), fewer than 5% of syndrome entries contain active detection events -- yet existing decoders process the entire syndrome volume. We introduce the Sparse Mamba Decoder (SMD), a defect-centric neural decoder that processes only the k active detection events using a 13-dimensional feature representation per defect and a Mamba state-space backbone, achieving $O(k)$ complexity. Across depolarizing, uniform circuit-level, SI1000, and Google Sycamore experimental benchmarks, SMD reduces the MWPM logical error rate by up to 49% at $d \le 5$ under SI1000 noise, runs 95-467x faster than the Tesseract near-MLD decoder and 232-463x faster than Belief Matching, and maintains nearly constant latency (24-57 us) across d = 3-9 under uniform circuit-level noise. On the Sycamore experimental dataset, the SMD ensemble matches or slightly surpasses the dense Mamba decoder of Varbanov et al. All results are obtained on commodity NVIDIA GPUs with 7.5-16M parameters, without specialized accelerators.

## 1. 核心问题与整体含义（研究动机与背景）

量子纠错（QEC）是构建容错量子计算机的关键，需要解码器同时满足高精度、低延迟和可扩展性。现有的神经解码器（如 AlphaQubit、AlphaQubit 2、Lee 等人的稠密 Mamba）虽然精度高，但都处理完整的征候阵列（大小为 $O(d^2R)$，其中 $d$ 为码距，$R$ 为测量轮数），无论实际错误率多低。在物理相关错误率（约 0.1%）下，活跃检测事件（缺陷）仅占征候条目的 3% 左右，但密集处理浪费了大量计算资源。因此，论文的核心动机是：**利用征候天然稀疏性，设计一种仅处理活跃缺陷的解码器，实现计算复杂度与错误数线性相关，而非与码距平方成正比，从而同时提升精度和速度。**

## 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**：采用“缺陷中心”（defect-centric）处理，仅提取活跃的检测事件（缺陷）作为输入，用 Mamba 状态空间模型（SSM）对变长缺陷序列进行线性时间处理，计算复杂度 $O(k)$（$k$ 为缺陷数），远小于传统密集解码器的 $O(d^2R)$。
- **关键技术细节**：
  - **16 维特征向量**（后文限定为 13 维，特征可参考式 (4)）：对每个缺陷编码以下属性：
    - 空间坐标 $(x_i, y_i)$（归一化旋转晶格坐标），归一化时间 $t/R$，稳定子类型 $\tau_i \in {0,1}$（X 或 Z 型）；
    - 四个空间邻域标志 $n_1–n_4$（同一轮中四个相邻稳定子是否也激活）；
    - 两个时间邻域标志 $n_5, n_6$（上一轮/下一轮该缺陷是否激活）；
    - 到 Z 和 X 逻辑边界的归一化距离 $b_Z, b_X$；
    - 重构测量值 $m_{i,t}$：对该稳定子的检测事件按时间进行累积异或（恢复原始稳定子测量值，提供状态信号）。
  - **架构流水线**（图 2c）：
    1. **缺陷嵌入**：对每个缺陷的 16 维特征，使用两层 MLP（含层归一化与 GELU）映射到模型维度 $d_{\text{model}}$。
    2. **L 个混合层**：每个混合层包含：
       - RMSNorm + Mamba 选择性扫描（状态维度 16，卷积宽度 4） + 残差连接；
       - RMSNorm + 门控密集层（SiLU 门控 + 残差），实现 token 内信息混合。
    3. **掩码平均池化**：对变长序列，通过二值掩码对有效缺陷的表示取平均。
    4. **读出网络**：可选 ResBlock 或简单 MLP，输出逻辑值 $\hat{\lambda}$（预测逻辑可观测量）。
  - **训练策略**：
    - 均匀电路级噪声/退极化噪声：从头训练，每轮新生成本地数据，使用 AdamW 优化器、余弦退火学习率调度。
    - SI1000 噪声：三阶段课程学习（最大轮数逐步增加：9→25→120），使用 Lion 优化器、EMA、BERT 式特征掩码正则化。
    - Sycamore 实验数据：先在标定 DEM 数据上预训练，再在真实实验数据上微调。
- **算法流程**（文字说明）：
  1. 对完整的 R 轮征候体，提取所有活跃检测事件（通过检测事件定义 $d_{i,t}=s_{i,t}\oplus s_{i,t-1}$）。
  2. 对每个缺陷构建 16 维特征向量，并按（时间主序，稳定子索引辅序）排序，形成长度为 k 的序列（填充至固定最大长度，附加掩码）。
  3. 通过嵌入层、L 个 Mamba 混合层、池化、读出，得到预测逻辑可观测量 $\hat{\lambda}$。
  4. 训练时最小化二分类交叉熵损失。

## 6. 主要结论与发现

1. **稀疏架构有效**：仅处理活跃缺陷的 SMD 在四种基准上均达到或超越密集解码器精度。
2. **显著速度优势**：
   - SI1000 噪声下比 Tesseract 快 95–467 倍，比 Belief Matching 快 232–463 倍。
   - 均匀电路级噪声下延迟几乎恒定（24–57 μs，d=3–9），而 Belief Matching 延迟增加 773 倍。
3. **精度提升**：

   - SI1000 噪声下 SMD 比 MWPM 降低 35-49% 的错误率（d=3,5），集成模型在 d=7 降低 16%。
   - Sycamore 数据上集成 SMD 匹配或略超稠密 Mamba 解码器。
4. **泛化能力**：d=5 的 SMD 在训练范围外（r=140）仍保持优势，表明稀疏表示可外推到更长序列。
5. **硬件友好**：参数量仅 7.5–16M，可在单块商用 GPU 上运行，无需专用 TPU。

## 7. 优点

- **新颖的稀疏输入范式**：开创性地将表面码解码从全征候处理转变为仅处理缺陷，灵感源自检测事件定义的稀疏本质，计算复杂度 $O(k)$ 随错误数线性增长，极具可扩展性。
- **精巧的特征设计**：16 维特征编码了空间、时间、邻域、边界、历史状态等丰富信息，使纯序列模型（Mamba）无需 2D 卷积即可捕获局部几何结构。
- **统一处理不同类型噪声**：单架构适应退极化、电路级、SI1000 和真实实验数据，展现了出色的泛化能力。
- **集成策略多样性**：利用不同训练检查点的多样性进行集成（SI1000 d=7、Sycamore 多阶段预训练检查点），而不单依赖随机种子，提升了集成增益。
- **严格的实验规范**：与多个基线在同一噪声模型和评估协议下比较，统计不确定性报告透明，训练数据量合理，未采用不公平的剪枝或特权信息。

## 8. 不足与局限

- **最大码距受限**：SI1000 实验只做到 d=7，未展示在大码距（d≥9）下的性能与可扩展性。
- **单次解码延迟较高**：批量推断时每拍延迟 4-12 ms（batch=1），不满足超导量子比特约 1 μs 的实时解码预算（作者承认需流式架构改进以进入亚微秒级）。
- **依赖 GPU 批量处理**：CPU 上的单次推断延迟可能更高，未报告终端用户 CPU 场景下的速度。
- **缺乏与 AlphaQubit 2 的直接对比**：后者在专用 TPU 上达成 <1 μs/cycle，SMD 目前无法在算力上匹敌；作者将优化方向归为未来工作。
- **特征设计未做系统性消融**：例如去掉邻域标志或重构测量值的影响未量化，读者不清楚各特征重要性。
- **训练计算开销**：虽然推断高效，但训练仍需大量样本（每个 epoch 数百万），且 SI1000 模型需 2.9M 步，资源需求不低。
- **仅针对旋转表面码**：未在颜色码、量子 LDPC 码等其他编码上验证，通用性有待进一步研究。
