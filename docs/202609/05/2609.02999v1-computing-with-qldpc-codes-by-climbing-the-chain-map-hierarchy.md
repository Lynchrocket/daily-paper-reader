## 摘要
我们开发了一个用于qLDPC码逻辑计算的框架，将逻辑Pauli、Clifford和非Clifford操作置于同等地位。这将Pauli逻辑算子的简单同调描述带入逻辑Clifford和非Clifford操作的拼图景观中，为发现新的逻辑门提供了工具。特别是，我们定义了链映射层级：一族链复形，其同调类编码任意Clifford层级上的逻辑酉操作和代码手术操作，与Pauli逻辑算子的链复形描述精确类似。因此，关于Pauli逻辑算子的直觉可用于发现在qLDPC码上的新逻辑操作。例如，用稳定子（即链复形的边界）变形Pauli逻辑算子的熟悉能力，成为搜索（非）Clifford逻辑门的常数深度酉实现的一种方式。利用这一策略，我们在任意数量的二维环面码块上发现了完整逻辑Clifford群的常数深度酉实现，包括在单个块内，以及在任意数量的三维环面码块上任意逻辑量子比特三元组上的可寻址逻辑CCZ门。在流形码之外，我们在具有许多编码量子比特的码上发现了可寻址非Clifford门。链映射层级自然涵盖并扩展了逻辑小工具的其他构造，例如提供了杯积的通用参数化。因此，我们的工作为使用qLDPC码进行计算提供了一个统一、有用且直观的语言。

## Abstract
We develop a framework for logical computation with qLDPC codes that places logical Pauli, Clifford, and non-Clifford operations on the same footing. This brings the simple homological description of Pauli logicals to the patchwork landscape of logical Clifford and non-Clifford operations, providing a tool for the discovery of new logical gates. In particular, we define the chain map hierarchy: a family of chain complexes whose homology classes encode logical unitary and code surgery operations at any level of the Clifford hierarchy, precisely analogous to the chain complex description of Pauli logicals. Consequently, intuition for Pauli logicals can be leveraged to discover new logical operations on qLDPC codes. For instance, the familiar ability to deform Pauli logicals with stabilizers---i.e. boundaries of the chain complex---becomes a way to search for constant-depth unitary implementations of (non-)Clifford logical gates. Using this strategy, we discover constant-depth unitary implementations of the full logical Clifford group on any number of blocks of the 2D toric code, including within a single block, and addressable logical CCZ gates on any triple of logical qubits on any number of blocks of the 3D toric code. Beyond manifold codes, we find addressable non-Clifford gates on codes with many encoded qubits. The chain map hierarchy naturally encompasses and extends other constructions of logical gadgets, for instance providing a universal parameterization of cup products. As such, our work provides a unified, useful, and intuitive language for computing with qLDPC codes.

## 2. 方法论

### 2.1 核心思想
- 鉴于逻辑 Puali 门是链复形中的 0-cycle/0-cocycle，逻辑 Clifford 门（如 CZ、CNOT）原本可视为两个链复形之间的 Chain Map。作者把“两个链复形之间的 Chain Map”进一步组织成一个新的链复形，即**链映射复形（Chain Map Complex）**[ C[2] ]，也称为 internal hom。
- 这个链映射复形的 0-cycle 正好就是保持（上）同调结构的 Chain Map，对应逻辑 Clifford 门；0-boundary 则对应逻辑平凡的 Clifford“稳定子”，可对物理门实现进行等价变形。这样，逻辑 Clifford 门就与一个具体 CSS 码的 Pauli 逻辑门完全对应。

### 2.2 关键技术细节
- **同构关系**：对 CSS 码链复形 C• 和 D•，链映射复形 [ C[2] ] ≃ D• ⊗ C•，即两个二维码的逻辑 Clifford 门可“读作”张量积（超图积）码的 Pauli 逻辑门。例如，两个 2D toric code 间的逻辑 CZ 门，可以用 4D toric code 中的 2D sheet 型 Pauli Z 逻辑门来直观刻画。对 2D toric code，T ⊗ T 构造对应的 4D toric code 是“免费”的几何图画。

### 2.3 递归构造：Chain Map Hierarchy
- 为了处理 Clifford 以上层级的门，作者递归构造链映射层级：[ C[ℓ] ] ≃ [C^(i_ℓ), [C^(i_{ℓ-1}, …, C^(i_1))]] ≃ C^(i_ℓ) ⊗ … ⊗ C^(i_1)。其中 ℓ=1 层描述 Pauli Z (C_0Z)；ℓ=2 层描述 CZ (C_1Z)；ℓ=3 层描述 CCZ (C_2Z)；依此类推。
- 计算流程可理解为“自底向上/自顶向下”的逻辑代数步骤：
  1. **自上而下（链映射 → 物理门）**：给定一个物理 tensor/矩阵 f，其分量 f^{α_1…α_ℓ} 指定哪些物理量子比特上施加物理 C^{ℓ-1}Z 门（通过 exp(iπ f n_1 ⊗ … ⊗ n_ℓ) 或分组乘积）。
  2. **同义变换（变形）**：逻辑门的任意给定实现均可叠加以 null-homotopic chain map（对应 Clifford/非 Clifford 稳定子）而保持逻辑效果不变，但支持区/权重/深度会变。边界对应稳定子路径。
  3. **S 门等量子比特内的门**：由于 S、S† 生成 Z4 结构，需要使用 Z4 lift 的链复形，并以对称 chain map 的受限/对称子复形来描述 intra-block Clifford 门。
- 用户最终感受到的实际操作是：比如“一次逻辑 CZ 可以由 Sheet-like 4D Pauli 逻辑经过 tent 形状的形变压缩为常数深度逻辑门”，这就是他们在文中声称能实现全套 Clifford 门的关键算法原理。

### 2.4 “理论物理”式的 Gates to Code 设计准则
- **改进版维度判据**：对 D 维流形 CSS 码，Z 逻辑是 D_Z 维；如果在 ℓ 阶 Clifford 层想要达到 transversal 实现，那么 ℓ ≤ D / D_Z。这推广了 Bravyi–König 定理并给了一个启发式（非形式化）证明：局部而言，空间维数受限，非本地 QLDPC 的 transversal 可实现级别也受约束。
- **张量积/超图积技巧**：对张量积码（toric code、3D toric code、某类 fracton 码如 ALP code），可以直接在因子码间用“tent map/平移/reflection/降维嵌入等”找到、压缩和再组合逻辑门。

## 6. 主要结论与发现

1. **统一框架**：Pauli、Clifford 和非 Clifford 逻辑操作都可以放在同一链复形/同调框架下，逻辑门与链复形同调类一一对应（对 Pauli、CZ、CCZ、S 等）。
2. **新结果**：对 2D toric code 的任意 N 个 block（或乃至单个 block）可实现整套 Clifford 群的常数深度实现；具体得到可寻址的 CZ、CNOT、S 和 Hadamard 门。
3. **3D Toric Code 的新非 Clifford 门**：任何 3D toric code block 的任意三个逻辑量子比特可实现 addressable CCZ 门（包括同一 block 内的逻辑 CCZ）。
4. **非流形 fracton 码**：在 ALP code 和 3ALP 类码中获得可寻址 Clifford 与 CCZ 门，这为拥有多逻辑量子比特的非流形码提供新的逻辑操作工具。
5. **推广的统一性**：推导出 cup product 的普适参数化，阐明如何在链映射层级中定义 cup product 和 cohomology invariants，说明其空间大于此前文献的既有“cup product”构造集合。
6. **No-go 判据**：给出 基于维数/交点的启发式论断，把 Bravyi–König 式 no-go 推广到非局部相互作用，从维度角度给出为什么只有某某些阶梯的 Clifford 门才是 transversal 可实现的。

## 7. 优点

- 理论上优美统一：将 Pauli 逻辑、Clifford 与非 Clifford 门的分析以同调代数语言压缩为同一抽象，直观且不失去严谨性。
- 实际工程价值强：直接给出了在三种主要码族（环面码、3D toric code、fracton 码）上若干组新 transversal 逻辑门的构造流程，它们是有明确深度和规则的结构，可转化为物理线路图。
- 对“为什么某个门可 transversal 实现”的判定在二维/三维流形码中得到一个通用维数瓶颈式准则，超越以往的 no-go 定理。
- 明确讨论了和常见 code surgery、cup-product 等新构造的关系，并能生成 cup product 中没有直接泛化过的 subspace 结果；因此该框架同时在方法论和扩展文献上起普遍作用。

## 8. 不足与局限

- **历史性与操作性限制**：它目前主要在码的理论层面论证和推导了构造，并未建立“任意 qLDPC 码都能得到完整 Clifford 群/CCZ”的通用判定性定理；它在每个具体码族的构造十分依赖已知同调/自同构/几何结构。
- **稀疏化算法仍未完全形式化**：给定某个逻辑动作，找出可常数深度的逻辑实现（sparsify representative），在文中依然被承认是类似最小权逻辑算符的高难问题，只提供较启发式方法。
- **应用门槛**：其对非流形码（fracton 码）的结构适用性明显受到这些码的几何、线状/平面子系统的约束，仍需对一般 product codes 或 lifted product codes 充分延伸。
- **语言和记号很重**：对读者而言需要较深的同调代数背景；很多图中“形式”与“物理门”的转换细节并未在每个 case 完全展开（如 S 门 Z4 细节），对于直接实现而言不若数值经典算法友好。
- **formal no-go**：虽然给出了Bravyi–König式维度不完全的推演，但又声明这是“informal argument”，未来需彻底形式化证法，以避免在低能物理无关或 non-manifold code 处出现边界反例。
- **没有仿真实验**：鉴于其声称的创新价值高，但未对 noise、threshold、physical qubit count 等做实际 数值验证，故难以直接回答“容错阈值提升多少”这类实用问题，属于纯数学/QEC 结构层面上的贡献。
