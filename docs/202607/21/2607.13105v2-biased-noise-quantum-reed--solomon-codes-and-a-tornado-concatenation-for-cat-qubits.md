## 摘要
耗散猫量子比特以平均光子数指数级抑制一种泡利错误通道，使得共轭比特翻转错误成为主要的失效模式。这种强噪声偏置使得通用量子纠错的完整机制变得不必要：一个码只需保护单一错误类型，且任何经典线性码都可以提升为恰好实现此功能的克利福德稳定子码。我们利用这一观察构建了一个仅比特翻转的量子Reed-Solomon（RS）码。从GF(2^3)上的最大距离可分RS码[7,3,5]出发，我们将其二进制扩展为GF(2)上的线性码[21,9,6]，并实现为[[21,9,d_X=6,d_Z=1]]比特翻转码，其稳定子为Z算符的乘积。由于不尝试相位翻转校正，该构造丢弃了标准量子RS码用于校正Z错误的冗余——强偏置猫量子比特使其变得不必要——并生成一个可直接在Stim中采样的浅层克利福德电路。错误通过最优有界距离综合征查表解码。随后我们引入一种龙卷风架构：将外层RS码的每个位置用内层距离三重复码包裹的两层级联，得到一个[[63,9,18]]码，通过两阶段内层多数投票和外层查表解码器解码。蒙特卡洛模拟表明，在物理比特翻转率p=0.1时，龙卷风码的逻辑错误率pL≈5.3×10^{-3}，低于其父码，且在低p下逻辑错误率按pL ∝ p^{6}缩放，而重复码为p^{2}，独立RS码为p^{3}。我们给出了精确构造、错误与电路模型、渐近缩放分析，以及关于开销成本和单次假设的诚实说明。

## Abstract
Dissipative cat qubits exponentially suppress one Pauli error channel with the mean photon number, leaving the conjugate bit-flip error as the dominant failure mode. This strong noise bias makes the full machinery of general quantum error correction unnecessary: a code need only protect against a single error type, and any classical linear code can be promoted to a Clifford stabilizer code that does exactly this. We use this observation to build a \emph{bit-flip-only} quantum Reed--Solomon (RS) code. Starting from the maximum-distance-separable RS code $[7,3,5]$ over $\GF(2^3)$, we binary-expand it to the linear code $[21,9,6]$ over $\GF(2)$ and realize it as a $[[21,9,d_X=6,d_Z=1]]$ bit-flip code whose stabilizers are products of $Z$ operators. Because no phase-flip correction is attempted, the construction discards the redundancy that standard quantum RS codes spend on correcting $Z$ errors -- which a strongly biased cat qubit renders unnecessary -- and yields a shallow Clifford circuit that samples directly in Stim. Errors are decoded by an optimal bounded-distance syndrome-lookup table. We then introduce a \emph{Tornado} architecture: a two-layer concatenation that wraps every position of the outer RS code in an inner distance-three repetition code, yielding a $[[63,9,18]]$ code decoded by a two-stage inner majority vote and outer lookup decoder. Monte-Carlo simulation shows that at a physical bit-flip rate $p=0.1$ the Tornado code reaches a logical error rate $\pL \approx 5.3\times10^{-3}$, below both parent codes, and that its logical error rate scales as $\pL \propto p^{6}$ at low $p$, in contrast to $p^{2}$ for the repetition code and $p^{3}$ for the standalone RS code. We give the exact construction, the error and circuit model, an asymptotic scaling analysis, and an honest account of the overhead cost and single-shot assumptions.
