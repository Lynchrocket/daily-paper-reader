## 摘要
量子LDPC码的发现需要在搜索大型代数设计空间的同时，可靠地验证任何候选码的参数和等价类。我们引入了一种大语言模型引导的进化工作流，其中语言模型对生成双变量自行车码和扰动双变量自行车码ansätze的Python程序进行变异。在五次实验中，该系统执行了约1650次进化迭代，筛选了约2×10^5个候选码，消耗了约140小时的计算时间和约400美元的大语言模型推理成本。候选码通过一个分阶段验证流水线进行评估，该流水线结合了GF(2)秩计算、距离估计与认证、混合整数线性规划、BLISS Tanner图去重、可分解性分析以及局部-Clifford等价性检查。在块长度n ≤ 360时，该工作流识别出465个不同的候选码：97个CSS双变量自行车码和368个非CSS扰动变体。CSS搜索恢复了已知的高性能码，并发现了新的有限长度代表，包括一个不可分解的[[288,16,12]]码以及距离d=8时k高达50的高权重码。非CSS搜索产生了在[[144,12,12]]处匹配总码品质因子的扰动码，以及根据MILP状态报告为认证值或上界的额外高距离候选码。总体而言，这些结果表明，当与独立评估相结合时，大语言模型引导的程序进化可以作为结构化量子码发现的实用工具。

## Abstract
Quantum LDPC code discovery requires searching large algebraic design spaces while reliably certifying the parameters and equivalence classes of any candidates found. We introduce an LLM-guided evolutionary workflow in which language models mutate Python programs that generate bivariate-bicycle and perturbed bivariate-bicycle code ansätze. Across five campaigns, the system performed approximately 1{,}650 evolutionary iterations, screened about $2 \times 10^5$ candidate codes, and required ${\sim}140$ hours of computation and ${\sim}$US\$400 in LLM inference cost. Candidate codes are evaluated through a staged validation pipeline combining $\mathrm{GF}(2)$ rank computation, distance estimation and certification, mixed-integer linear programming, BLISS Tanner-graph deduplication, decomposability analysis, and local-Clifford equivalence checks. At block length $n \leq 360$, the workflow identifies 465 distinct candidate codes: 97 CSS bivariate-bicycle codes and 368 non-CSS perturbed variants. The CSS search recovers known high-performing codes and finds new finite-length representatives, including an indecomposable [[288,16,12]] code and higher-weight codes with up to $k = 50$ at distance $d = 8$. The non-CSS search produces perturbed codes matching the gross-code figure of merit at [[144,12,12]], along with additional high-distance candidates reported as certified values or upper bounds according to MILP status. Overall, these results show that LLM-guided program evolution can serve as a practical tool for structured quantum-code discovery when paired with independent evaluation.

## 1. 论文的核心问题与整体含义（研究动机和背景）

量子低密度奇偶校验（qLDPC）码对于容错量子计算至关重要。其中，双变量自行车（BB）码因其权重为 6 的稳定子、恒定深度的纠错码、优异的率–距离–阈值权衡（级联码）而具有吸引力，特别是 [[144,12,12]] 的“总码”（gross code）实现了约 0.7% 的伪阈值。然而，在实用的块长度（n ≲ 1000）下，BB 码的设计空间仍然很大、未被充分探索。之前的最高权重 6 的编码维度 k ≤ 12（后达到 k=16），更高编码率是否可行、对距离的影响如何，缺乏系统性研究。本文旨在利用大语言模型（LLM）引导的进化搜索来高效探索这一设计空间，发现新码并揭示结构特性。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 将 LLM 作为变异算子应用于进化搜索（类似 FunSearch / AlphaEvolve），变异的是生成编码的 Python 程序（ansatz），而非单个码本身。这样一次变异可以表达代数模式（如“使用 x^{ℓ/3}”），从而在所有格点维度上泛化。
- 采用 MAP-Elites 归档，按两个行为维度（产生高 k 码的格点数量、总高 k 码数）分布种群的多样性。

### 关键技术细节
- **进化流程**：种子程序 → LLM 建议 diff → 生成变异程序 → 多阶段验证管线。
  - 阶段1: k 筛选（GF(2) 秩计算，~2s），丢弃无有效码的程序。
  - 阶段2: BP-OSD 距离估计（~30-60s，多译码器配置）。
  - 阶段3: MILP 精确距离验证（仅离线或后期插入）。
- **验证管线**：GF(2) 秩、BP-OSD 距离、MILP（HiGHS）、BLISS Tanner 图去重、Tanner 图可分解性分析、局部 Clifford 等价性检查（针对非 CSS 码）。
- **码构造**：
  - CSS BB 码：定义在环 R = F₂[x,y]/(x^ℓ-1, y^m-1) 上，由两个权重-3 多项式 A,B 生成，重量 6 稳定子。
  - 非 CSS 扰动 BB (PBB) 码：增加扰动多项式 C,D，产生混合稳定子，通过对称性约束验证可交换性。
- **信度过滤**：d/√n 阈值，防止低距离高 k 码支配适应度（但 BP-OSD 不可靠时效果有限）。
- **自适应非 CSS 距离管线**：穷举权重枚举 + MILP + 可达综合征采样（修复 BP-OSD 对非 CSS 码的失败）。

## 5. 实验数量与充分性

共进行 5 次进化实验加 3 种消融（随机、GA、GA-G），每次进化实验内含大量迭代。在所有实验中得到 465 个不同码，97 CSS，368 PBB。充分性与客观性：作者提供了详细的消融对比，指出 LLM 发现高距离码的能力优于 GA（GA 只能得到低距离码），但 LLM 自身 fitness 信号被 BP-OSD 高估所污染。公平性方面，GA-G 使用了更少的评估次数（14k vs 213k），因此不能直接等预算比较，但定性结论合理。

## 6. 论文的主要结论与发现

1. **新码发现**：在 n≤360 下获得 465 个不同码，包括：
   - CSS 码：[[288,16,12]]（不可分解，全部位移 ≤3），[[288,50,8]]（重量-8 稳定子），[[144,8,12]] 等。
   - PBB 码：[[144,12,12]]（匹配总码 FOM=12 但具有非 CSS 结构），[[360,12,≤24]]（FOM≤19.2）。
2. **BP-OSD 高估**：对高码率码（k/n>0.1），BP-OSD 高估距离最多达 12 倍（MILP 精确验证），147/154 码的界限被收紧。A=B 情况 BP-OSD 未能检测到 d=2。
3. **率–距离权衡**：经验性发现所有搜索到的 BB 码家族服从一条权衡：高 k 对应低 d，反之亦然。重量-6 码中 k>24 则 d≤4；不可分解的 d=12 码 k≤16。重量-8 码略扩充但未突破。
4. **结构分类**：识别出四种代数家族：单变量/HGP 码（k 高但 d≤4）、x/y-交换码（唯一达到 d≥12 的权重-6 家族）、混合单项式/高重码、非 CSS PBB 码。
5. **Tanner 图可分解性**：[[288,24,12]] 被证明是两个总码的直和，通过管道检测并排除。
6. **管道设计至关重要**：多阶段级联、后处理验证（BLISS、Clifford 检查）防止了虚假发现。

## 7. 优点

- **方法创新**：将 LLM 程序进化引入量子码发现，能够生成结构化的代数模式，而非仅枚举参数元组。
- **全面的验证管线**：结合 GF(2) 秩、BP-OSD、MILP、图去重、可分解性、局部 Clifford 等价，大大提升了可靠性，避免了仅依赖 BP-OSD 的陷阱。
- **可复现性**：代码、数据、所有进化历史公开发布。
- **消融设计**：比较了 LLM、GA、随机搜索，揭示了 LLM 在创造高距离码上的优势。
- **对现有认知的贡献**：量化了 BP-OSD 的过估程度，鉴定了直和码、A=B 陷阱等，为后续研究提供了验证标准。

## 8. 不足与局限

- **搜索空间受限**：要求 3 | ℓ 在阶段1，错过了 (16,9) 和 (18,8) 格点；非 CSS 实验排除大 m 格点 (12,12)、(15,12)（MILP 耗时过高）。
- **BP-OSD 高估污染进化适应度**：在 C1-C3 中进化 fitness 使用 BP-OSD 距离，导致搜索偏向高 k 而低 d 的码，尽管 k 是准确的。
- **率–距离权衡是否是结构限制？** 作者指出未证明这是构造的结构约束，可能是搜索不完全的假象。
- **非 CSS 的局部 Clifford 等价检查存在覆盖缺口**：不能排除所有可能的单比特 Clifford 模式（如非均匀 SH/HSH 及跨类别模式）。
- **硬件可行性未深入探讨**：不同稳定子重量对应不同的电路深度，PBB 码的混合稳定子还需要 CZ 门，故障纠正电路仍有挑战。
- **仅考虑码容量模拟，未进行电路级噪声仿真**。
