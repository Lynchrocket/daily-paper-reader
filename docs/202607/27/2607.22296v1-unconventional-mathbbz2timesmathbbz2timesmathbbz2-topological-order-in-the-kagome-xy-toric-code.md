## 摘要
我们研究了Kagome晶格上XY环面码（XYTC）的量子相图，该模型由XY六边形和平行四边形算符以及守恒的星算符组成。通过利用十二边形上的精确局域$\mathbb{Z}_2$对称性，我们解析地证明，在六边形算符较大的极限下，Kagome XYTC实现了$\mathbb{Z}_2\times\mathbb{Z}_2\times\mathbb{Z}_2$拓扑有序相。这种非常规拓扑相包含64种准粒子——阿贝尔任意子——它们在三个彩色子晶格上具有受限的迁移率，从而建立起量子维度为8。大量的拓扑超选择扇区源于六个独立的Wilson环算符，它们作为涌现的一阶形式对称性。由此产生的任意子结构比已知的拓扑码（如环面码和颜色码）更加丰富。我们构建了相应的CSS拓扑稳定子码，为拓扑量子信息的编码和操控开辟了新的可能性。

## Abstract
We investigate the quantum phase diagram of the XY toric code (XYTC) on the kagome lattice consisting of $XY$ hexagonal and triangular plaquette operators and conserved star operators. We demonstrate analytically by exploiting an exact local $\mathbb{Z}_2$-symmetry on dodecagons that the kagome XYTC realizes a $\mathbb{Z}_2\times\mathbb{Z}_2\times\mathbb{Z}_2$ topologically ordered phase in the limit of large hexagonal \mbox{plaquette} operators. This unconventional topological phase involves 64 quasi-particles - Abelian anyons - with restricted mobility on three colored sublattices establishing a quantum dimension of eight. The large number of topological superselection sectors originates from six independent Wilson loop operators, acting as emergent one-form symmetries. The resulting anyon structure is richer than that of established topological codes like the toric and the color code. A corresponding CSS topological stabilizer code is formulated, opening novel possibilities for the encoding and manipulation of topological quantum information.
