## 摘要
量子纠错解码器通常针对合成电路级噪声进行基准测试，其假设是解码器在此类噪声下的排名可迁移至硬件，并随着噪声模型变得更加真实而有所改善。Willow处理器作为首个在表面码阈值以下运行的处理器，使我们得以检验这一假设。我们使用一个四级噪声模型阶梯（保真度递增）对六个解码器组成的小组进行排名，并依据跨越三种码距、两种基和十五种轮数的真实数据进行评估。当噪声模型为每种操作类型分配各自的错误率时，与硬件的排名一致性得以显现。将模型校准至该设备可改善绝对错误率，但并不能提升排名一致性。此外，我们还在码距低于其训练感受野以及通过映射到其训练所用晶格上的条件下，对NVIDIA的Ising预解码器在硬件上进行了首次独立评估。在这些条件下，它并不具备精度-延迟优势：在280次评估中的278次中，小组中另一解码器在每周期错误率和解码延迟方面均匹敌或优于它。我们发布了完整流程及每次评估的逐次结果，以便未来解码器和设备能够进行比较。

## Abstract
Quantum error-correction decoders are typically benchmarked against synthetic circuit-level noise, under the assumption that a decoder's ranking under such noise transfers to hardware and improves as the noise model becomes more realistic. The Willow processor, the first to operate below the surface-code threshold, allows us to test this assumption. We rank a panel of six decoders using a four-rung ladder of noise models with increasing fidelity, evaluated against real data across three code distances, two bases, and fifteen round counts. Rank agreement with hardware appears once the noise model gives each operation type its own error rate. Calibrating the model to the device improves absolute error rates but not rank agreement. We additionally provide the first independent evaluation of NVIDIA's Ising pre-decoder on hardware, at code distances below its training receptive field and via a mapping onto the lattice on which it was trained. Under these conditions, it holds no accuracy-latency advantage: another panel decoder matches or improves on it in both per-cycle error rate and decode latency in 278 of the 280 evaluations. We release the full pipeline and the per-shot outcome of every evaluation, so future decoders and devices can be compared.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **核心问题**：量子纠错解码器的性能排序通常在**合成电路级噪声模型**下进行验证，并隐含一个关键假设——该排序能**迁移到真实硬件**，且噪声模型越贴近真实设备，排序越可靠。本文利用首个在**表面码阈值以下运行**的 Willow 处理器（Google）公开发布的数据集，直接检验了这一假设。
- **背景动机**：选择正确的解码器对于在固定硬件上实现更低的逻辑错误率至关重要，而这一选择依赖于基准测试方式能否反映硬件真实表现。现有新解码器（如 NVIDIA 的 Ising 预解码器）几乎完全基于合成噪声验证其收益，从未在欠阈值硬件上得到独立检验。Willow 的公开数据让这种检验首次成为可能。
- **论文整体贡献**：证明了一个反直觉的结论——合成噪声模型对设备的**保真度并不决定其能否正确排序解码器**；排序可靠性主要由噪声模型是否具备**电路级结构（per-operation 独立错误率）** 决定，而非校准精度。

## 2. 论文提出的方法论

### 2.1 核心思想
构建一个**噪声保真度阶梯（noise-fidelity ladder）**，即四级由弱到强利用设备信息的合成噪声模型。将同一面板（panel）的解码器分别在四级合成噪声和真实 Willow 数据上解码**完全相同的电路**，以真实硬件排名作为基准，评估每一级合成模型排名与硬件的吻合程度，实现严格受控的"消融比较"。

### 2.2 输入处理管线（Ingest Pipeline）
- 设备原始数据仅含**测量记录**（measurement record）与 **sweep bits**（随机化预备态的比特）。
- 检测事件（detection events）与可观测翻转（observable flip）均由理想电路重新计算，而非直接使用附带的预处理结果。
- 检测事件的定义依赖于 sweep bits 的读取，否则会产生从未实际制备过的量子态的伪信号。
- 合成数据在同一管线的更早阶段进入，作为测量记录的第二个来源，使真实与合成运行仅有噪声来源的差异，从而保证逻辑错误率完全可比。

### 2.3 四级噪声保真度阶梯
| 阶梯（Rung） | 类型 | 关键特征 |
|---|---|---|
| ① 均匀去极化（Uniform depolarizing） | 未校准 | 单一全局错误率作用于所有操作；电路结构正确但边权系统性错误 |
| ② SI1000 | 未校准 | 标准超导电路级模型，各类操作错误率呈固定比例，单参数 p 缩放 |
| ③ 25 参数拟合 | 已校准 | 25（实际 23 个自由）物理分组参数，从各 patch 的检测事件分数和两两检测器相关矩阵（p_ij）拟合；因 X/Z 基共享物理制备与测量，X/Z 对称性无法区分 |
| ④ 综合征估计 DEM | 已校准 | 逐边独立估计检测器错误模型，允许任何参数的 25 参数模型无法产生的边权 |

### 2.4 解码器面板（Decoder Panel）及评估方式
- 六种解码器共 8 项配置：MWPM（PyMatching 实现）、BeliefMatching、BP+OSD、BP+LSD、Tesseract、两个尺寸的 Ising 预解码器（fast/accurate）、MWPM-RL（只跑真实数据）。
- 每个解码器读取**检测器错误模型（DEM）**作为先验；唯一例外是 Ising，它不读取先验，先验只在后续的匹配步骤介入。
- 评分为**逻辑错误率**（预测逻辑翻转与记录翻转不一致的占比），累计率经保真度反演公式转换为**每周期错误率**：ε_cycle = ½[1 − (1−2ε)^(1/r)]。
- 排名一致性用 **Kendall's τ** 和 p 值量化（τ=1 表示排序完全一致）。

### 2.5 Ising 输入映射适配
- Willow 检测事件格式与 Ising 期望的 CSS 风格张量输入不兼容，需经**适配器**重排为（层、稳定子类型、x、y）键对应的格式。
- 四种晶格取向（XV、XH、ZV、ZH）均可将 Willow 的 XZZX 稳定子映射到 CSS 网格；默认选取 XV，另在附录 C 测试其余取向。

## 6. 论文的主要结论与发现

1. **噪声模型保真度与排名一致性无单调关系**：并非越接近设备噪声，排名越准确。未校准的 SI1000 在 d=7 达到 τ=1.000，反而胜过两种已校准模型（τ=0.905 和 0.810）。
2. **电路级结构是决定排名可靠性的关键**：均匀去极化噪声与硬件排序吻合差（τ≈0.619–0.714，部分不显著）；而所有携带**按操作类型区分错误率**的模型均 τ≥0.810——即使该模型不包含任何设备数据。
3. **校准提升绝对精度但不提升排名准确性**：25 参数拟合与综合征估计 DEM 的绝对 LER 最接近硬件，但在 d=7 的排序反而不如 SI1000。原因是数据量随码距增长而稀释：d=7 仅 1 patch 支撑复杂度随 d² 增长的解码图，综合征估计 DEM 的最大边概率高达 0.442（接近 0.5 即边权接近零，携带很少信息）。
4. **X/Z 基不对称性无法被任何 Pauli 噪声模型捕捉**：Willow 上 X 基在所有 24 个解码器–距离单元中更差（高 4%–39%），但两种已校准模型在 21 个单元中仅有 14 个和 11 个重现该趋势，甚至出现反向。原因是 Willow 的 X 基预备/测量经 Hadamard 共轭由 Z 操作实现，原理上无法用对称噪声区分。
5. **NVIDIA Ising 预解码器在硬件上无优势**：在全部 280 项评估中 278 项被至少一个其他解码器在**每周期错误率和延迟两方面同时匹敌或超越**；是面板中唯一错误率随码距增大而上升的解码器（d=3→7 增加 1.84 倍，而其他解码器均改善）；错误率随轮数减少源于固定的单次错误贡献被更多周期稀释。四种晶格取向仅改变量化程度不改变结论。
6. **对先验的敏感度可作为解码器选择标准**：不同解码器对先验错误的脆弱性路径不同（BP 系受全局扁平先验影响严重；MWPM 对少数退化边敏感；Tesseract 等相对稳键）。匹配的先验条件下报告的排名差可能掩盖先验敏感性的巨大差异。
7. **实际含义**：在解码器筛选中，一个合成模型的价值来自其电路级结构而非校准精度；与其仅优化匹配度，不如构建**携带逐边不确定性的估计器**。

## 7. 优点：方法与实验设计的亮点

- **首次硬件锚定**：利用首个低于阈值的处理器数据检验了一个此前从未被验证的核心假设，极具领域价值。
- **严谨的消融设计**：四级噪声阶梯是受控变量消融——电路相同、评分相同，只有噪声来源与模型不同，因果可归因清晰。
- **细致的管线工程**：从原始测量记录出发重建检测事件（而非使用被处理过的发布数据），并严格考虑 sweep bits 移位校验，确保数据前端的正确性。
- **完整的统计框架**：Bootstrap 排名翻转概率、参数扰动扫描、多种晶格取向验证、三重验证门，统计结论稳健。
- **独立第三方评估的价值**：首次由作者团队之外独立评估 NVIDIA Ising 预解码器，并给出开放管线与**全部逐次射击级数据**，使未来解码器不经硬件访问即可与设备结果对比。
- **发现了校准工作中被忽视的维度**：将"预测设备行为"与"正确排序解码器"分离为两个可能冲突的优化目标，对噪声估计领域有方法论的推动意义。

## 8. 不足与局限

- **d=7 数据稀缺**：只有一个物理 patch，无法分离码距效应与数据量/病态条件效应；SI1000 在 d=7 的 τ=1.000 可信度有限（各解码器仅有 6–32 个逻辑错误）。
- **噪声模型空间有限**：四种模型均为随机 Pauli 信道，无法表示泄漏、串扰、漂移、软读出或宇宙射线事件等设备实际噪声结构。
- **面板规模限制统计分辨率**：7 项排序对应仅 21 个有序对，τ 每次移动约 0.095；可区分"非随机一致"与"随机"，但不能精细区分不同模型的一致程度。
- **验证方案不对称**：AlphaQubit 因不可复现未纳入面板；Ising 在低于其训练感受野（R=9, 13）的条件下评估，且需经适配映射——无法严格区分性能不足是源于模型本身局限还是评估条件偏差（但附录 C 已排除主要映射偏差）。
- **X/Z 不对称不可估计**：由于 Willow 编译方式（X 基由 Z 操作共轭实现），任何 Pauli 模型在原理上无法捕捉该设备不对称性——这是一个模型表达力的结构性上限。
- **对比基准时间维度单一**：所有评估基于同一时期的设备数据，未考虑随时间的漂移或量子处理器的非平稳性。
