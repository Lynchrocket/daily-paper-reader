## 摘要
伊辛框架将量子纠错中的解码问题映射为经典哈密顿量的基态优化，其中$X$-$Z$误差相关性作为交叉项出现。在现象学去极化噪声下，精确的联合公式对于环面码包含最多8体相互作用，对于$6.6.6$色码包含10体相互作用。这些高阶项会降低求解器的收敛性、增加运行时间，并在嵌入到本征二体伊辛硬件时提高辅助自旋开销。在本工作中，我们提出了迭代低阶解码（ILOD）算法，该算法在$X$型和$Z$型子哈密顿量之间交替，通过贝叶斯先验近似交叉型相关性，利用另一种类型的推断错误配置重新加权每种类型的耦合。这使哈密顿量中相互作用项的最大体数减半，加速了求解器，恢复了更大码距下的收敛性，并将二体嵌入的总自旋数减少了$2.5$倍。对于环面码，ILOD实现了$4.73\%$的阈值，而联合公式为$4.83\%$，经验运行时间比率缩放为$(0.81)^d$。对于$6.6.6$色码，在小编码距离下，两者的阈值在统计不确定性内一致，且对于更大距离，即使联合公式因退火预算不足而无法收敛，ILOD仍能保持收敛。

## Abstract
The Ising framework maps the decoding problem in quantum error correction onto ground-state optimization of a classical Hamiltonian, in which $X$-$Z$ error correlations enter as cross terms. Under phenomenological depolarizing noise, the exact joint formulation contains up to 8-body interactions for the toric code and 10-body for the $6.6.6$ color code. These high-order terms degrade solver convergence, inflate runtime, and raise the auxiliary spin overhead when embedding into native 2-body Ising hardware. In this work, we propose the iterative low-order decoding (ILOD) algorithm, which alternates between $X$- and $Z$-type sub-Hamiltonians, approximating cross-type correlations through Bayesian priors that reweight each type's couplings using the other type's inferred error configuration. This halves the maximum body count of interaction terms in the Hamiltonian, accelerating the solver, restoring convergence at larger code distances, and reducing the total spin count for 2-body embedding by a factor of $2.5$. For the toric code, ILOD attains a threshold of $4.73%$ versus $4.83%$ for the joint formulation, with the empirical runtime ratio scaling as $(0.81)^d$. For the $6.6.6$ color code, their thresholds agree within statistical uncertainty for small code distances, and ILOD remains convergent for larger distances where the joint formulation fails to converge despite a larger annealing budget.

- **整体含义**：提出一种迭代低阶解码（Iterative Low-Order Decoding, ILOD）框架，通过交替求解X型和Z型子哈密顿量，并用贝叶斯先验近似交叉关联，将最大交互体数减半，显著提升解码器的可扩展性和实际可行性。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 不直接优化包含高阶交叉项的联合哈密顿量，而是将其分解为X型和Z型两个独立的子哈密顿量，通过交替迭代求解，并利用贝叶斯规则从另一子系统的推测错误配置来动态修正本子系统的耦合强度，从而近似捕获X-Z相关性。

### 关键技术细节
1. **子哈密顿量构造**（代码容量噪声下）：
   - $H_X^{(\nu)}(\sigma) = -\sum_{q=1}^n J_{X,q}^{(\nu)} \eta_q^X \prod_{j} \sigma_j^{S_{j,q}^X}$
   - $H_Z^{(\nu)}(\mu) = -\sum_{q=1}^n J_{Z,q}^{(\nu)} \eta_q^Z \prod_{l} \mu_l^{S_{l,q}^Z}$
   - 形式上与比特翻转噪声下的伊辛模型相同，但具有依赖于迭代步数的qubit耦合强度$J_{X,q}^{(\nu)}$和$J_{Z,q}^{(\nu)}$。

2. **贝叶斯耦合更新**（以$\hat{e}_X \to J_Z$方向为例）：
   - 根据$X$类型的估计$\hat{e}_{X,q}$，计算条件概率$p_{Z,q}^{(\nu)}$：
     - 若$\hat{e}_{X,q}=1$（推断为X或Y错误），则$p_{Z,q}=1/2$（等概），从而$J_{Z,q}=0$，该qubit从$Z$子问题中移除。
     - 若$\hat{e}_{X,q}=0$（推断为I或Z错误），则$p_{Z,q}=p/(3-2p)$（较小），$J_{Z,q}$较大，增强对Z错误的惩罚。
   - 本地尼西森条件关联：$\beta J_{Z,q}^{(\nu)} = \frac{1}{2}\ln\frac{1-p_{Z,q}^{(\nu)}}{p_{Z,q}^{(\nu)}}$。

3. **软决策鲁棒性**（针对非理想求解器）：
   - 引入可靠性参数$a, b$表示求解器正确估计的概率，对上述硬分配进行平滑，避免错误信息刚性传播。
   - 参数通过离线校准获得（每个错误率$p$下，从校准集估计条件频率）。

4. **算法流程**（Algorithm 1）：
   - 初始化：$J_{X,q}^{(1)}$基于无条件边际$p_X=2p/3$。
   - 每轮迭代$\nu$：
     - 求解$H_X^{(\nu)}$（枚举$2^k$个逻辑类），得到最优类$\hat{\ell}_X^{(\nu)}$、规范自旋配置$\sigma^{(\nu)}_{\text{opt}}$和错误估计$\hat{e}_X^{(\nu)}$。
     - 用$\hat{e}_X^{(\nu)}$按贝叶斯规则更新$J_{Z,q}^{(\nu)}$。
     - 求解$H_Z^{(\nu)}$，得到$\hat{\ell}_Z^{(\nu)},\mu^{(\nu)}_{\text{opt}},\hat{e}_Z^{(\nu)}$。
     - 检查是否收敛；若$\hat{e}$不再变化或达到最大迭代数$N_{\text{iter}}=4$，终止。
   - 输出联合逻辑类$\hat{\ell}=(\hat{\ell}_X,\hat{\ell}_Z)$。

5. **现象学噪声扩展**：
   - 将qubit索引扩展为时空索引$(q,t)$，引入时间类规范自旋$\xi_{q,t}^X,\xi_{q,t}^Z$，子哈密顿量包含数据项、测量项和最终边界项。
   - 仅数据耦合$J_{X/Z,q,t}$被动态重加权，测量耦合$J_m$和边界项$J_s$保持不变。

- **实用性强**：针对原生二体伊辛硬件设计，显著降低辅助自旋数量，有利于在相干伊辛机、量子退火器等平台上部署。

## 8. 不足与局限

- **近似性质**：ILOD是对精确联合后验的近似，在码容量噪声下环面码阈值有微小损失（0.56%），在某些场景可能不可忽略。
- **可靠性参数依赖**：参数$(a,b)$需离线校准，且文中假设为静态（仅用首轮），若求解器可靠性随迭代变化或噪声模型变异，需重新校准，增加部署复杂度。
- **噪声模型限制**：当前仅考虑现象学和码容量独立去极化噪声，未扩展到更现实的电路级噪声（含关联错误、测量错误时间相关性等）。作者也承认此为未来工作。
