## 摘要
解码是量子纠错（QEC）的基本组成部分，它将稳定子测量结果转化为纠正操作，从而抑制逻辑错误并保护逻辑量子信息。构建容错架构需要增加码距，这反过来对解码准确性、可扩展性和实际可部署性提出了越来越高的要求。尽管已经提出并展示了各种解码算法，但实现可靠、可扩展和实时的解码仍然是一个重大挑战。机器学习（ML）方法特别适合这一场景，因为量子错误解码本质上是一个处理具有复杂时空相关性的大量经典数据的问题。本章综述了基于ML的量子错误解码方法，重点关注拓扑码，并强调架构原理、实际性能和实时性考虑。我们首先将解码定义为一个学习问题，并概述关键范式，包括判别式、生成式和强化学习公式。然后介绍支撑大多数当代神经解码器的神经网络构建模块，并讨论如何集成这些组件以平衡表达能力、可扩展性和延迟。基于这一架构视角，我们回顾了存储实验中神经解码的最新进展和基准，并讨论了实时解码、开放挑战以及迈向可扩展容错量子计算的未来方向。

## Abstract
Decoding is an essential component of quantum error correction (QEC), translating stabilizer measurement outcomes into corrective actions that suppress logical errors and preserve logical quantum information. Building fault-tolerant architectures requires increasing the code distance, which in turn places growing demands on decoding accuracy, scalability, and practical deployability. While a wide range of decoding algorithms have been proposed and demonstrated, achieving reliable, scalable, and real-time decoding remains a significant challenge. Machine-learning (ML) approaches are particularly well suited to this setting, as quantum error decoding is fundamentally a problem of processing large volumes of classical data with complex spatiotemporal correlations. This chapter surveys ML-based methods for quantum error decoding, with a focus on topological codes and an emphasis on architectural principles, practical performance, and real-time considerations. We first frame decoding as a learning problem and outline key paradigms, including discriminative, generative, and reinforcement-learning formulations. We then introduce the neural network building blocks that underpin most contemporary neural decoders and discuss how these components can be integrated to balance expressivity, scalability, and latency. Building on this architectural perspective, we review recent progress and benchmarks in neural decoding for memory experiments, and discuss real-time decoding, open challenges, and future directions toward scalable fault-tolerant quantum computing.

## 2. 方法论：核心思想、关键技术与算法流程

### 2.1 解码问题的形式化

- **稳定子码定义**：`[[n, k, d]]` 码，每个 QEC 周期测量 `m = n - k` 个稳定子生成元，得到综合征 `s ∈ {0,1}^m`。
- **最优解码目标**：
  - 非简并量子最大似然解码（QMLD）：选择单个最可能错误（NP-hard）。
  - 简并量子最大似然解码（DQMLD）：选择总概率最大的逻辑陪集（#P-complete）。
- **监督分类框架**：将解码视为从综合征 `x` 到逻辑类 `y` 的映射，学习目标是最小化逻辑错误率。误差分解为近似误差、泛化误差和优化误差三部分。

### 2.2 主要学习范式

- **判别式模型**：
  - 直接学习 `fθ: syndrome → logical correction`。
  - 两种输出形式：逻辑类（softmax 分类）或逐比特错误概率（回归 + 经典后处理）。
  - 典型代表：Varsamopoulos 的前馈网络、AlphaQubit（循环 Transformer）。
- **生成式模型**：
  - 建模条件分布 `P(E | s)`，通过采样或自回归生成恢复操作。
  - 典型代表：RBM（Torlai & Melko）、qecGPT（Transformer）、MADE、扩散模型（qLDPC）。
  - 优势：训练只需综合征-错误对，无需标签；可自然处理简并性。
- **强化学习（RL）**：
  - 将解码建模为顺序决策问题（MDP），智能体根据综合征选择局部纠错动作，以逻辑状态保持为奖励。
  - 典型代表：deep Q-learning 在 toric code 上的应用，可处理 depolarizing 噪声下的关联错误。

### 2.3 神经网络构建模块

- **RNN / LSTM**：处理多轮综合征历史，支持任意周期数，但串行计算导致时间维不可并行。
- **GNN**：利用 Tanner 图或探测器错误图，通过消息传递实现空间信息聚合，参数量不随码距增长，可跨距离泛化。
- **Transformer**：自注意力可捕获长距离时空关联，但平方复杂度成为瓶颈；典型应用包括 qecGPT（自回归生成）和 AlphaQubit（单次前向判别）。
- **状态空间模型（SSM）**：如 S4、Mamba，具有线性时间推理、并行训练能力，适合流式处理；Mamba 通过选择性扫描实现高效序列建模。
- **混合架构**：如 AlphaQubit 系列——空间混合（attention + 卷积）与时间递推结合；AlphaQubit 2 引入压缩和实时变体。

### 2.4 训练数据策略

- **模拟器生成**：使用 Stim 等稳定子电路模拟器生成训练样本（综合征-标签对）。
- **重要性采样**：在低物理错误率下提高高难度样本比例，改善训练效率。
- **对称性增强/等变架构**：利用码的平移、旋转、翻转等对称性减少数据需求。
- **Sim-to-real 迁移**：先在模拟数据上预训练，再用实验数据进行微调（AlphaQubit 范式）。

### 2.5 实时解码机制

- **指数积压问题**：若解码吞吐低于综合征产生速率，非 Clifford 自适应操作会导致等待时间指数增长。
- **滑动/并行窗口解码**：将时长划分为窗口，提交核心区、保留缓冲区，可实现并行解码并控制边界误差。
- **神经解码器实时化方向**：
  - 流式加速：设计低延迟架构（如 Mamba、卷积）提高吞吐。
  - 窗口化输出：训练模型输出窗口局部逻辑贡献，便于并行拼接。
