## 摘要
最小权完美匹配（MWPM）解码器是表面码的标准解码策略，但在有偏噪声下其性能显著下降。本文引入了一种改进的表面码，称为XYZ平面码，并将MWPM解码器扩展为后验MWPM（pMWPM），且几乎不增加解码复杂度。XYZ平面码在几乎所有偏置条件下均表现出比平面码更高且更稳定的阈值，同时实现了显著更低的逻辑错误率。具体而言，在无限偏置情况下，XYZ平面码的阈值相比表面码提升了约36%，而在其他偏置下也保持相当或更高的阈值——例如，在偏置η=1时阈值约为15.5%，在η=100时约为14.2%。此外，pMWPM可适用于多种改进的表面码，本文结果也表明其在Y算子涉及更多数据量子比特等场景中具有极好潜力。

## Abstract
The minimum-weight perfect matching (MWPM) decoder is a standard decoding strategy for surface codes, but its performance degrades considerably under biased noise. In this paper, a modified surface code, termed the XYZ planar code, is introduced, and the MWPM decoder is extended to posterior MWPM (pMWPM) with almost no increase in decoding complexity. The XYZ planar code exhibits higher and more stable thresholds than the planar code under almost all bias conditions, while also achieving significantly lower logical error rates. Specifically, in the infinite-bias case, the threshold of the XYZ planar code is improved by about \(36\%\) compared to that of the surface code, and it maintains comparable or higher thresholds under other biases -- for example, the threshold reaches approximately \(15.5\%\) at bias \(η= 1\) and \(14.2\%\) at \(η= 100\). Furthermore, pMWPM can be adapted to a wide range of modified surface codes, and the results presented in this work also indicate its excellent potential in other scenarios, such as configurations in which \(Y\) operators involve a larger number of data qubits.

- **研究背景**：已有研究针对偏置噪声提出了 XY 表面码、XZZX 表面码等 Clifford 变形表面码，这些码在特定偏置下能达到接近哈希界的阈值。MWPM 是实时量子纠错的有力候选解码器，但现有方案在偏置噪声下需重新优化。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：
    1. **修改表面码结构**：将所有 Z 稳定子替换为 ZY 稳定子（即在一个数据量子位上使用 Y 算子，其余三个使用 Z 算子），构成非 CSS 类的 XYZ 平面码。
    2. **设计后验 MWPM (pMWPM) 解码器**：利用 ZY 稳定子测量结果的后验概率重新赋权，提升对 Z 错误的解码能力，再依次解码 X 错误。
- **关键技术细节**：
    - **XYZ 平面码构造**：在标准平面码的方格中，对某些 Z 稳定子用 Y 算子替换一个 Z 算子，形成 Z₂Y 或 Z₃Y 稳定子。Y 算子只出现在特定行（第 4i-1 行）的数据量子位上，这些量子位同时参与两个 ZY 稳定子（称为中心量子位）。逻辑 Z 算子需避开 Y 算子作用的数据量子位，逻辑 X 算子仍为垂直 X 算子链。
    - **pMWPM 解码步骤**：
        1. **计算后验概率**：对于每个“中心量子位”（同时参与两个 ZY 稳定子的数据量子位），根据其相邻两个 ZY 测量结果 (s₁, s₂) 和周边量子位的翻转概率，计算该量子位遭受 Z 或 Y 错误的后验概率 \(P(Z \cup Y \mid s_1,s_2)\)，进而得到动态权重。
        2. **Z 错误解码**：用更新后的权重构建 Z 校验子图，运行 MWPM 得到 Z 错误估计 \(\hat{e}_Z\)。
        3. **修正 ZY 测量结果**：对每个中心量子位，若 \(\hat{e}_Z\) 在该位置有 Z 错误，则翻转其相邻两个 ZY 稳定子的测量结果（模 2 加 1），得到修正后的 ZY 综合征 \(s'_{ZY}\)。
        4. **X 错误解码**：以恒定权重（曼哈顿距离）构建 X 校验子图，对 \(s'_{ZY}\)（此时反映 X 或 Y 错误）运行 MWPM 得到 X 错误估计 \(\hat{e}_X\)。
    - **复杂度**：pMWPM 相比标准 MWPM 仅增加了常数因子的额外计算（重心权重计算和一步综合征修正），渐进复杂度仍为 \(O(n^3 \log n)\)，接近线性（实际使用中可通过稀疏开花等优化）。
- **公式/算法**：
    - 后验概率公式（式 6）：
      \[
      P(Z\cup Y\mid S_1,S_2)=
      \begin{cases}
      p_y+p_z, & \text{if } S_1\neq S_2,\\[4pt]
      \dfrac{p_z O_n^2 + p_y E_n^2}{p_{\text{noflip}} E_n^2 + p_{\text{flip}} O_n^2}, & \text{if } S_1=S_2=0,\\[4pt]

      \end{cases}
      \]
      其中 \(E_n, O_n\) 分别为 n 个外围量子位产生偶数/奇数翻转的概率，n=2 或 3。
