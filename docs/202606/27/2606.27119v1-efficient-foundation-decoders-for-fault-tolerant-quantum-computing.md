## 摘要
基础解码器是一类高容量神经解码器，凭借在较大码距下准确高效的解码能力，成为容错量子计算的主要候选方案。然而，它们的构建常常面临严峻的扩展障碍，因为更大的码距会迅速放大综合征生成和神经优化的成本。为解决这一瓶颈，我们在此提出了神经迁移统一框架（NTU），这是一个用于高效基础解码器的统一框架。NTU的一个核心特征是能够通过可扩展码族共享的代数结构，对齐不同码距下的解码任务，从而使在较小码上学习到的知识能够加速大规模解码器的训练。我们将NTU实例化为NTU-Transformer，这是一种专门针对平面表面码和二变量自行车码设计的基于Transformer的神经解码器。对于电路级噪声下的平面表面码，NTU-Transformer在[![361,1,19]!]码上优于相关感知匹配，并进一步扩展到[![625,1,25]!]码，通过迁移自适应超越了标准匹配。对于[![72,12,6]!]的二变量自行车码，在低物理错误率区域，它超越了Relay-BP。这些结果确立了我们的方案作为可扩展路径，用于容错量子处理器基础解码器的跨距离分摊训练。

## Abstract
Foundation decoders, a class of high-capacity neural decoders, are leading candidates for fault-tolerant quantum computing, with accurate and efficient decoding at large code distances. However, their construction often faces a steep scaling barrier, as larger code distances rapidly amplify the cost of syndrome generation and neural optimization. To address this bottleneck, here we devise neural transfer unification (NTU), a unified framework for efficient foundation decoders. A central feature of NTU is its ability to align decoding tasks across code distances via algebraic structures shared by scalable code families, which enables knowledge learned on smaller codes to accelerate large-scale decoder training. We instantiate NTU as NTU-Transformer, a transformer-based neural decoder tailored for planar surface codes and bivariate bicycle codes. For planar surface codes under circuit-level noise, NTU-Transformer outperforms correlation-aware matching on the $[\![361,1,19]\!]$ code and further scales to the $[\![625,1,25]\!]$ code, where it exceeds standard matching through transfer adaptation. For the bivariate bicycle code with $[\![72,12,6]\!]$, it surpasses Relay-BP in the low-physical-error regime. These results establish our proposal as a scalable route to amortized cross-distance training of foundation decoders for fault-tolerant quantum processors.

## 2. 论文提出的方法论

### 核心思想
- **尺度不变性（Scale Invariance）**：在可扩展的码族（如平面表面码、二元自行车码）中，随着码距增大，检测器（detector）的局部邻域结构保持相同（由有限相对移位集M(x,y,t;d)定义）。NTU利用这一性质，将不同码距下的解码问题对齐到共享表示空间，实现知识迁移。

### 关键技术细节
- **NTU框架四步**：
  1. **时空不变性发现**：识别码族中由相同相对移位规则生成的检测器邻域。
  2. **距离无关的综合征编码**：为每个检测器v构建特征h(v)=σ(∑_{u∈N(v;d)} w_{v^{-1}u} S_d(u))，其中权重w_{v^{-1}u}依赖于相对移位而非绝对位置，从而适用于不同码距。
  3. **神经解码**：对编码后的综合征应用神经解码器f(S_d;θ)（可选用任意架构，如Transformer或GNN）。
  4. **迁移适应**：先在小码距d上训练得到参数θ*，再初始化大码距d'的解码器为θ*，并通过微调适应更大码距。
- **NTU-Transformer实例化**：
  - **拓扑驱动嵌入**：使用关系索引的嵌入表Er[·]聚合二进制综合征的局部模式，嵌入参数跨码距共享。
  - **几何感知旋转位置编码（RoPE）**：基于检测器的代数坐标而非序列索引，使得注意力仅依赖于相对位移，避免绝对位置编码在码距变化时的失效。
  - **时空感知骨干**：交错使用GRU（沿时间维度传播）和Transformer层（沿空间维度混合令牌）。
  - **逻辑查询交叉注意力**：使用可学习的逻辑查询令牌（每个逻辑比特一个）对最终检测器令牌进行交叉注意力，输出k维逻辑错误概率，支持变长检测器集合。
  - **中间轮次蒸馏**：使用经典解码器（如相关PyMatching）为前缀综合征生成伪标签，提供密集监督信号，缓解冷启动问题。
- **NTU-Neural-BP实例化**：用于二元自行车码的物理错误推断范式的消息传递实例，共享本地更新规则，支持跨图大小迁移。

### 训练流程
- 在小码距d上使用损失函数L(T_d; θ)优化；然后使用参数θ*初始化大码距d'解码器，仅重新生成距离相关的缓冲区（如坐标图、掩码等），重置优化器后微调。

## 3. 实验设计

- **数据生成**：使用Stim模拟器在线生成标本（on-the-fly syndrome samples）。

### Benchmark与对比方法

### 评估指标

## 6. 论文的主要结论与发现

- **性能优越**：NTU-Transformer在表面码上超越相关PyMatching（d=19时LER 1.1e-8 vs 1.3e-8），在BB码[[72,12,6]]低错误率区超越RelayBP（p=0.1%时LER 1.8e-7 vs 3.5e-7）。
- **计算扩展显著降低**：NTU将训练计算量的扩展指数从Γ≈1.64降至Γ≈1.51，使得大码距解码器训练可行（扩展到d=25）。
- **冷启动问题有效缓解**：NTU初始化使训练精度迅速提升（d=19在750步内>99%），而从零训练在相同步数后仅50%（随机猜测）。
- **高重量错误区间优势**：NTU-Transformer在高检测器错误权重的样本上准确率显著高于匹配解码器（表面码d=19，重量772区间：99.90% vs 99.82%）。
- **组件重要性**：消融实验表明，几何感知RoPE和拓扑嵌入对NTU的迁移效率至关重要（特别在非局部BB码上）。
- **跨架构可行性**：NTU适用于Transformer和消息传递（Neural-BP）两种骨干网络，通用性好。

## 8. 不足与局限

- **码族覆盖有限**：仅验证了平面表面码和二元自行车码。其他有前景的码族（如超图乘积码、提升乘积码、Floquet码）未被测试，其尺度不变性可能存在差异或需要额外设计。
- **实时解码未解决**：NTU-Transformer具有约3200万参数，推理延迟可能不满足实时解码要求。论文仅在讨论中建议通过知识蒸馏、量化和剪枝压缩，但未提供实验。
- **逻辑电路场景缺失**：所有实验基于量子记忆实验（memory experiment），未涉及逻辑门操作（如Clifford门）下的解码，这是向实用容错量子计算迈进的必要步骤。
- **基线与训练设置差异**：
  - Tesseract在d>9时使用外推结果，可能不够准确。
  - d=23,25的压力测试使用了不同的噪声率（p_train=0.7% vs 0.5%）和更大GPU配置，该设置下的对比不能直接与主实验的缩放曲线合并，可能引入了偏差。
  - 消融实验中，BB码的零迁移效果（去除RoPE或嵌入后精度不提升）可能部分由于微调步数不足（仅5000步），但更长训练是否最终能超越随机猜测未探索。
- **可复现细节**：虽然代码开源且附有项目页面，但训练数据生成（在线采样）和超参数设置的敏感度未充分讨论，例如稳定器dropout策略的具体影响分析有限。
